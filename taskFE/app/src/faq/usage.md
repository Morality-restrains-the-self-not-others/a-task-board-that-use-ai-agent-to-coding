# 平台使用

## 如何创建项目？

登录后进入「项目」页面，点击「创建项目」按钮，填写项目名称与描述并选择所属工作区即可创建。创建后即可在项目内分配任务、跟踪进度。

## 云平台管理是做什么的？

「云平台管理」用于管理已安装的镜像、授权 AI 模型并监控云资源使用情况。你可以在其中查看镜像列表、管理授权状态以及跟踪资源消耗。

## 如何在任务中使用 AI 模型？

在任务详情中配置运行模板时，可指定平台与镜像。镜像需先在「云平台管理」中完成授权，未授权模型不可用于任务执行。

## 任务执行失败了怎么办？

1. 查看任务详情中的执行日志，定位失败原因。
2. 检查镜像授权与运行模板配置是否正确。
3. 若是环境问题，尝试重新运行任务。
4. 仍无法解决时，请发送邮件至 {{contactEmail}}，附上任务 ID 与日志片段。

## 如何邀请团队成员协作？

在项目/工作区设置中邀请成员加入，为其分配角色即可开展协作。成员权限由管理员在「用户和权限管理」中统一配置。

## 浏览器兼容性

建议使用最新版 Chrome / Edge / Firefox 浏览器访问平台，以获得最佳体验。

## 数据与备份

平台对核心数据提供定期备份与保护机制，避免因误操作或故障导致数据丢失。重要数据请勿依赖单点保存。
