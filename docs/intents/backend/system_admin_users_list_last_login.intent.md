# 功能意图：超管用户列表 API 回填 last_login

- **日期**: 2026-08-23
- **状态**: 实施中
- **接口**: `GET /api/system-admin/users/`

## 背景与目标

列表 DTO 需带 `last_login`（`auth_user.last_login`）。该列此前未在登录成功路径写入，展示会恒为空，须在认证成功时 touch。

## 范围与边界

- 范围内：系统管理列表 SELECT `last_login`；密码/OTP/access-token/微信/注册/activate-session 成功后更新 `last_login`。内部用户列表同步带该字段。
- 范围外：模拟登录不得把目标用户写成活跃；每请求更新。

## 约束与风险

- touch 失败不阻断登录（warn 日志）。
- 空值 JSON 为 `""`。

## 验收标准

1. 列表对已写入 last_login 的用户返回该字段。
2. 从未登录用户返回空串。
3. 密码登录成功后 last_login 非空。
