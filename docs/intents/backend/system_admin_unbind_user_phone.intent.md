# 功能意图：系统管理编辑用户时解绑手机号

- **日期**: 2026-08-28
- **状态**: 已实施
- **接口**: `PUT|PATCH /api/system-admin/users/{id}/`
- **页面**: `/system-admin/users/` 编辑用户模态框「手机号」

## 背景与目标

运营在编辑用户时清空手机号并保存，期望解除该账号的手机登录绑定。原先 `applyAdminLoginIdentifiers` 仅在 `phone != ""` 时 upsert，空字符串被当成「不改」，接口仍 200、弹窗关闭，但 `auth_login_method` 的 phone 行仍活着，列表继续显示原号码。

## 范围与边界

- 范围内：admin PUT/PATCH 请求体**包含** `phone` 且 trim 后为空 → 作废该用户全部未作废 phone login method；幂等（已无绑定仍 200）。前端编辑弹窗提供「解绑」清空字段，保存后列表手机号为空。
- 范围外：请求体省略 `phone` 键（部分更新不碰手机号）；邮箱解绑；管理员 reclaim 他人号码；用户自助解绑。

## 约束与风险

- 不得把完整手机号写入日志（PII）。
- 只作废 `object_id = 目标用户` 的 phone 行，不得误伤共享该号的其他账号。
- 省略 `phone` 不得解绑，避免只改角色标志时误清号码。

## 验收标准

1. PUT `phone: ""`（键存在）→ 200，该用户无活 phone login method，列表 `phone` 为空。
2. PUT 省略 `phone` → 原绑定不变。
3. 已无手机号再 PUT 空 `phone` → 200，仍无绑定。
4. 编辑弹窗「解绑」清空 `#edit-phone`；保存请求体含 `phone: ""`。
