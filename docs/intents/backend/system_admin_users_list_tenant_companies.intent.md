# 功能意图：超管用户列表 API 回填所属租户公司

- **日期**: 2026-08-23
- **状态**: 已实施
- **接口**: `GET /api/system-admin/users/`

## 背景与目标

列表 DTO 需带 `tenant_companies`，供超管 UI 展示；公司数据所有权在 taskTenantService。

## 范围与边界

- 范围内：分页列表批量调用 `POST /api/internal/tenant/members/batch-get/`，只收录 `is_active` 成员。
- 范围外：内部 `GET /api/internal/users/`、用户详情 PATCH、写成员关系。

## 约束与风险

- 禁止直连租户表。
- 下游失败 best-effort：空数组，HTTP 仍 200。
- 日志不含内部密钥与完整联系方式。

## 验收标准

1. 活跃成员公司出现在对应用户的 `tenant_companies`。
2. 停用成员不出现。
3. 下游宕机时列表成功且该字段为空数组。
