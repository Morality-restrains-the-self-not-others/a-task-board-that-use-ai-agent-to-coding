## 功能意图

1. 在 `/tenant/{tenant}/work-panel/` 看板中，用户新建任务成功后，该任务默认出现在目标进度列的**最上方**。
2. 刷新或重新拉取任务列表后，新建任务仍保持在同列上方（相对未手动拖拽重排的旧任务）。
3. 拖拽重排仍以 `order` 升序为准（数值越小越靠上）；新建任务通过分配「当前工作区最小 order − 1」实现置顶。
4. 列表接口同工作区任务按 `order_num ASC, created_at DESC` 返回，与看板前端排序一致。

## 范围

- 服务：`taskTaskService` 创建任务 `order_num` 分配与列表排序。
- 前端看板已按 `order` 升序展示，无需改排序算法。
