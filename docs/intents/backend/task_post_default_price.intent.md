# 意图：任务帖默认定价 0.55 元/帖/12个月

## 背景与目标

任务帖创建按「1 帖配额 = 12 个月存续期」计费。目录默认单价历经 0.33 元 → 1 元 → 0.55 元 → 0.33 元。产品要求将**购买**默认定价改为 **0.55 元/帖/12个月**；续存只扣配额、不另扣费（见 `task_post_renewal_quota_only`）。

## 范围与边界

- 范围内：`billing_unit.server_start` 的默认 `price`（分）；Go 缺行回退；公开/管理定价 API 缺行回退；前端价格管理占位与测试夹具。
- 范围外：不改存续期（仍为 12 个月）；不改配额消耗规则；不覆盖管理员已改成非 33 分的目录价；不改支付/下单流程；不改 `server_start_renewal`（续存标价保持 0）。

## 约束与风险

- 金额以「分」为 SSOT；0.55 元 = 55 分。
- 存量库仅把仍为上一版默认 33 分的 `server_start` 行更新为 55 分。
- DDL/种子只走 `dataMigrate/taskBill/` + 9999，业务进程不迁移。
- 管理员 PUT 只改创建帖目录价；续存不写入标价单位。
- 040 曾把 100→55；042 把 55→33。二者已记入 `data_migrate_log`，不会重跑。本轮用 **045** 把仍为 33 的创建帖行改为 55。

## 验收标准

1. 全新迁移后 `billing_unit.server_start.price = 55`，单位为 `帖/12个月`。
2. 续存不按 `server_start_renewal` 标价扣费（见续存配额意图）。
3. 库中无对应行时，Go 回退 `DefaultTaskPostUnitPriceCents = 55`，公开 API `task_points = 55`。
4. 价格管理页占位示例为 0.55。
5. 已改为其他价格（非 33 分）的 `billing_unit` 行不被迁移覆盖。

1. 常量 `DefaultTaskPostUnitPriceCents = 55`，所有缺行回退引用该常量。
2. `dataMigrate/taskBill/045_update_task_price_055.sql`：33→55（仅 `server_start`）。
3. 前端夹具与占位改为 0.55；单测锁定 55 分。
