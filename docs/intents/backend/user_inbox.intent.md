# 功能意图：用户收信箱

- **日期**: 2026-08-23
- **状态**: 实施中
- **服务**: taskAuth / taskFE
- **ADR**: ADR-0038

## 背景与目标

登录用户可在账号中心阅读发给自己的站内信。系统管理员以该用户身份登录成功后，必须留下一封含代登理由的信。

## 范围与边界

- 范围内：GET/PATCH 本人信件；模拟登录自动写信。
- 范围外：用户互发私信、邮件推送、租户公告。

## 验收标准

1. GET `/api/auth/inbox/` 只返回当前登录用户的信。
2. 不得通过改路径或 id 读取他人信件。
3. 模拟登录成功后出现 kind=`impersonation_notice` 且 body/reason 含管理员理由。

## 业务意图 → 事件对照

| 业务意图 | 事件名 | MQ | 消费者 |
|----------|--------|----|--------|
| 新站内信 | UserInboxMessageCreated | user-inbox-message-created | 本期无自动消费者 |
