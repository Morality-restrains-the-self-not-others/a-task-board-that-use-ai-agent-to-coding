# 意图：工作空间任务帖人读序号

## 背景与目标

看板把技术 ID 后 6 位当任务编号。`genID` 是纳秒时间戳，后几位在同一工作空间内无序，人读像乱序。

目标：同一租户同一工作空间内，任务帖获得不可变递增序号，展示为 `#N`。技术主键不变。存量清空后从 1 起号。

## 范围与边界

- 范围内：`task_tasks.workspace_seq`；发号表 `task_workspace_seq`；创建事务内发号；任务 JSON / `TASK_CREATED` 带序号；FE 卡片、父任务/派生自、搜索、复制短号、任务详情「任务辅助信息」面板。
- 范围外：不改 `id` / `genID`；不改 `order_num` 语义；不给评论编号；不级联清空跨服务 CSC / 凭证；不清 `task_git_identities`。

## 约束与风险

- 发号与插帖同一事务，`SELECT FOR UPDATE`，禁止无锁 `MAX+1`。
- `UNIQUE(tenant_id, workspace_id, workspace_seq)`；删除不回收。
- 按序号搜索必须带 `tenant_id + workspace_id`。
- 存量：迁移清空本服务任务帖及相关行（见设计 §5.1），不回填。
- DDL 只走 `dataMigrate/taskTaskService/` + 9999，业务进程不迁移。

## 验收标准

1. 空工作空间连续建 3 帖 → `workspace_seq` 为 1、2、3，卡片为 `#1` `#2` `#3`。
2. 创建响应与列表/详情均含 `id` 与 `workspace_seq`。
3. 删中间帖后再建，序号继续递增、不复用已分配号。
4. 搜索 `#2` / `2` 只命中当前工作空间该序号；完整 `task_…` 仍按主键。
5. 单击复制 `#N`，双击复制完整技术 ID。
6. 父任务 / 派生自文案为 `#N` 或 `#N 标题`，不再出现后 6 位。
7. 任务详情「任务辅助信息」展示「任务编号」`#N`（无序号时 `—`），技术 ID 仍可复制。
