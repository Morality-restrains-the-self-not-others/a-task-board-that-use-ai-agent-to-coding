# 功能意图：编辑用户表单显示用户 ID

- **日期**: 2026-08-23
- **状态**: 实施中
- **页面**: `/system-admin/users/` 编辑用户模态框

## 背景与目标

编辑表单目前有用户名、邮箱、手机号、密码与角色勾选，没有用户 ID。排障与对照列表时需要在弹窗内直接看到 Snowflake ID（字符串）。

## 范围与边界

- 范围内：编辑模态框只读展示当前 `editUserId`。
- 范围外：添加用户表单（尚无 ID）、修改 ID、列表列改动。

## 约束与风险

- ID 按字符串展示，禁止当 number 渲染以免精度丢失。
- 只读，不进入保存请求体。

## 验收标准

1. 编辑弹窗有「用户ID」字段，值为当前用户 `id` 的十进制字符串。
2. 控件 `readonly`，保存 PUT 体不含该展示字段。

## 业务意图 → 事件对照

| 业务意图 | 事件名 | 例外理由 |
|----------|--------|---------|
| 查看编辑中用户 ID | （无） | 纯前端只读渲染，无新写路径 |
