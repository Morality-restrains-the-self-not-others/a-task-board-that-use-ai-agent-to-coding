# 功能意图：推荐资格管理分成比例固定 5%

- **日期**: 2026-08-25
- **状态**: 已实施
- **页面**: `/system-admin/referral-management`

## 背景与目标

分成比例不再由超管配置。政策恒为 **5%**：管理页只读展示，点数计提与微信打款均使用该比例（打款 `min(5%, 微信商户 max_ratio)`）。禁止从 `billing_referral_config` 读取比例。

## 范围与边界

- 范围内：推荐资格管理页比例卡片；申请列表/stats/performance 展示；计提与打款口径。
- 范围外：微信商户平台 `max_ratio` 查询；入账天数；资格审批。

## 约束与风险

- 前端不得出现可编辑比例输入或保存按钮。
- 前端不得把 GET config 的 `referral_rate_percent` 绑到 UI。
- 后端 `getReferralRatePercent` / `configuredReferralRateDisplay` 禁止读库。
- 打款仍受微信商户上限约束。

## 验收标准

1. 比例卡片只读展示 `5%`（`data-testid="referral-rate-fixed"`），文案含「固定为 5%」。
2. 不存在 `referral-rate-input`、`referral-ratio-save`、`referral-ratio-range`。
3. GET config 返回 12 时管理页仍展示 5%。
4. 申请列表仍一列「分成比例」，接口回传恒为 5%。
