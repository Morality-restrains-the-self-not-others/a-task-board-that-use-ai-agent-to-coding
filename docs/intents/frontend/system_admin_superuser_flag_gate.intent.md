# 功能意图：编辑用户「超级用户」仅系统管理员可改

- **日期**: 2026-08-23
- **状态**: 实施中
- **页面**: `/system-admin/users/` 添加/编辑用户模态框

## 背景与目标

选择器指向编辑表单「超级用户」复选框。仅平台角色 `super_admin`（或持有 `platform:manage`）可勾选/取消；其它进入系统管理的账号只读该标志，保存时不得提交 `is_superuser`。

## 范围与边界

- 范围内：添加与编辑模态框复选框、写请求省略未授权字段。
- 范围外：列表角色徽章、RBAC 角色管理页。

## 验收标准

1. `super_admin`：添加/编辑复选框可交互。
2. 非系统管理员：编辑复选框 `disabled`；添加表单不提供可写超级用户控件。
3. 非系统管理员保存编辑时请求体不含 `is_superuser`。

## 业务意图 → 事件对照

| 业务意图 | 事件名 | 例外理由 |
|----------|--------|---------|
| 勾选超级用户 | （无） | 前端仅门闩；后端既有 create/patch，无新成功路径 |
