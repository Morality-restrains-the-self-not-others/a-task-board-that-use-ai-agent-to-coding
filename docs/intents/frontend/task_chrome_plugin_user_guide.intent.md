# 意图：Chrome 插件内置使用说明区域

## 背景

`taskChromePlugin` 功能较多（登录、浮窗建任务、指针选元素、DevTools 单请求/批量捕获），用户缺少统一的页内说明入口；Agent 新增功能时也易遗漏文档。

## 意图

1. 在浮窗、DevTools 面板、扩展弹窗放置可折叠/独立 Tab 的使用说明区域，内容覆盖现有主要能力。
2. 以 `docs/USER_GUIDE.md` + `lib/user-guide.js` 为双 SSOT，并用目录 `ai.md`（及 `.ai.md` 符号链接）强制后续用户可见功能同步更新说明。

## 非目标

- 不替代仓库 README 的开发者安装说明
- 不做多语言 i18n

## 业务意图 → 事件对照

| 业务意图 | 领域事件 | MQ Topic | 说明 |
|----------|----------|----------|------|
| 插件内展示使用说明 | （无） | — | **无对应事件**：纯前端/扩展 UI 文档展示，不改变服务端聚合状态，不投递业务事件 |
