# 功能意图：价格管理/购买页展示 4 元/GB/月与起购 10 GB

## 背景与目标

管理端价格管理页当前展示 8.00 元/GB/月；购买页磁盘输入 `max=1`。应对齐后端目录：展示 4.00 元/GB/月，购买时 0 表示不买、大于 0 则至少 10 GB。

## 范围与边界

- 范围内：`SystemAdminResourcePricingPanel.vue` 展示与占位；`OrderCreate.vue` 数量输入与提交前校验；`Pricing.vue` 最低购买数量文案
- 范围外：管理端改价 API 契约；赠送页数量下限

## 约束与风险

- 纯展示与前端校验；权威仍在 taskBill
- 磁盘数量为 0 表示本单不买磁盘，不得把 HTML `min` 设为 10 否则无法跳过
- 无新服务端事件

## 验收标准

1. 价格管理页当前定价卡片在 API 返回 4.00 时展示「4.00 元/GB/月」
2. 购买页去掉 `max=1`，展示起购 10 GB；填 1–9 不 POST，提示起购
3. 定价页 GitLab 磁盘「最低购买数量」为 10 GB，不再写累计限购 1 GB
