# 任务详情目录栏 / 内容预览可拖动分隔

## 变更记录

- 2026-07-19：任务详情「文件变动」与「项目文件树」中，目录栏与内容预览由固定 `md:grid-cols-[minmax(14rem,18rem)_1fr]` 改为可拖动分隔；宽度本地持久化。

## 意图

用户在任务详情查看层文件变动或项目文件树时，可拖动中间分隔条调整左侧目录栏宽度，便于对照长路径与右侧内容预览。

## 范围

- `ResizableSplitPane` 组件 + `useResizableSplitPane` 宽度钳制/持久化
- 接入：`TaskDetailExecLayerChanges.vue`、`TaskDetailProjectFileTree.vue`
- md+ 横向分栏可拖；小屏仍纵向堆叠（无分隔条）

## 非目标

- 不改动预览内容协议或 Git 暂存操作
- 不引入第三方 split-pane 库

## 业务意图 → 事件对照

**无对应事件**：纯前端布局交互与本地宽度持久化，无服务端业务状态变更。

| 业务意图 | 事件名 | 例外理由 |
|---------|--------|---------|
| 目录栏/预览可拖动分隔 | — | 纯前端展示/交互例外 |
