# 功能意图：项目详情运行模版摘要显示价格

## 用户故事

作为租户成员，我在项目详情页「基本信息 → 运行模版摘要」一眼看到已选实例的**按量付费价格**，以便在不下滚到「项目运行模版」规格行时判断成本。

## 验收标准

1. 项目已配置运行模版且硬件面板已拿到实例价格时，「运行模版摘要」文本在身份摘要（云账号/区域/实例规格）后追加 `· 价格 <金额> 元/时`（或等价币种后缀）。
2. 价格未返回前可不显示价格段；价格加载中时可显示 `· 价格加载中…`。
3. 未配置模版时仍显示「未设置」，不追加价格。
4. 同一摘要不重复拼接多个「价格」段。
5. UI 锚点：`data-testid="project-run-template-summary-text"`。
6. 「项目运行模版」面板内「规格」行继续展示完整 CPU/内存/GPU/价格（既有行为不变）。

## 范围

- 前端：`projectRunTemplateUtils.js`（价格片段提取与拼接）、`ProjectDetail.vue`、`ProjectRunTemplatePanel.vue`（向上抛出 `spec-summary-change`）
- 不含：后端持久化历史价格、改计费逻辑、任务详情页临时配置横幅文案
