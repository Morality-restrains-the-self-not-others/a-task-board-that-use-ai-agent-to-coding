# 功能意图：系统管理订单页按微信账单单号查询

## 意图

管理员把微信商户后台导出的微信支付单号或商户订单号粘贴到「交易单号」输入框即可查单；Excel 反引号不影响查询。展开详情可见这两类凭证。

## 角色

- 系统管理员 / 平台员工

## 行为

1. 交易单号输入框说明支持：展示订单号、主键、微信支付单号、商户订单号。
2. 提交前去掉首尾空白与 `` ` `` / 引号，再请求 `GET /api/system-admin/orders/?order_number=`。
3. 空输入本地提示、不发请求（只读查询；同步门闩防连点）。
4. 展开详情展示「商户订单号」「微信支付单号」（来自详情 API）。

## 非目标

- 在列表行内直接展示完整单号（避免表格过宽）。
- 改变微信关联账号 Tab。

## 业务意图 → 事件对照

前端只读查询，无新事件。
