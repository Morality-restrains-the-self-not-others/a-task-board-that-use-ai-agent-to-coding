# 意图：DevTools 请求列表可过滤、可按列排序

## 背景与目标

DevTools「单请求创建」已能按文本/方法/状态筛选，但排序固定为时间倒序，且 HAR 资源类型未暴露。用户需要像 Chrome Network 一样缩小列表并点列头排序后再点选请求。

## 范围与边界

- **范围内**：DevTools 单请求 Tab 的搜索、方法、状态、资源类型过滤；方法/状态/URL/耗时/时间列表头排序。
- **范围外**：Popup 请求预览排序 UI；Chrome Network 过滤语法；服务端 API。

## 验收标准

1. 搜索、方法、状态过滤行为与现网一致（含 canceled）。
2. 类型芯片可只显示 XHR/Doc/JS/CSS/Img/Other。
3. 点击表头排序；同列再点切换方向；默认时间倒序。
4. 空匹配显示「暂无匹配的请求」。
5. 使用说明写明过滤与排序。

## 业务意图 → 事件对照

| 业务意图 | 领域事件 | MQ Topic | 说明 |
|----------|----------|----------|------|
| 过滤/排序本地请求列表 | （无） | — | **无对应事件**：纯浏览器扩展本地视图 |

## 权限边界

仅当前 inspected tab 的 Network 快照；无新权限、无新 HTTP。
