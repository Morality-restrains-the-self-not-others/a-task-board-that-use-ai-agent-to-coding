# 功能意图：用户列表「是否获得分账资格」列

## 意图

系统管理员在用户表格中直接看到「是否获得分账资格」。

## 角色

系统管理员。

## 行为

1. 表头在「角色」后、「操作」前增加「是否获得分账资格」。
2. `has_profit_sharing_qualification === true` 显示「是」；`false` 显示「否」；其余显示「—」。
3. 空列表 colspan 随列数 +1。
4. 只读，无新写按钮。

## 非目标

- 不在本列提供审批/取消操作。

## 业务意图 → 事件对照

| 业务意图 | 事件名 | 例外理由 |
|----------|--------|---------|
| 查看分账资格列 | 无对应事件 | 纯前端只读渲染；数据由后端列表 GET 提供 |

## 验收标准

- 表头顺序正确。
- 是/否/— 三态与字段一致。
