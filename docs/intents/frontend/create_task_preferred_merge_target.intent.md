## 变更记录

- 2026-07-12：创建任务时目标分支默认不再写死 develop；在共有分支中按 develop → release/* → main 选取，都没有则留空。

## 功能意图

1. WorkPanel「创建任务」打开时，目标分支初始为空。
2. 所选项目全部仓库分支加载并求交后，自动填入优先默认：
   - 有 `develop` → `develop`
   - 否则有 `release` 或 `release/...` → 取字典序最大的一条
   - 否则有 `main` → `main`
   - 否则保持空
3. 用户手动改过目标分支后，不再被后续分支刷新覆盖。
4. 编辑已有任务时，保留已保存的 merge target，不套用上述默认。
