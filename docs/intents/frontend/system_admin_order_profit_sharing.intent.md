# 功能意图：管理端订单展开展示分账、租户端不展示

## 意图

系统管理「订单记录」展开区在行项明细下方展示「分账」：接收方与金额。租户「订单列表」展开与订单详情页不出现该区块。

## 角色

- 平台员工：可见
- 租户成员：不可见

## 行为

1. 管理员展开调用 `GET /api/system-admin/orders/{id}/`，把 `profit_sharing` 传入 `OrderExpandDetail`。
2. 有记录：表格「分账接收方 / 金额（元）/ 状态」。
3. 无记录：文案「本订单无分账记录」。
4. 租户展开不传 `profitSharing`（保持 `null`），不渲染分账标题与表格。
5. 不展示 openid。Anti-Replay-OK：只读展开，无写按钮。

## 非目标

- 不在租户推荐收益页重复本表
- 不提供管理员编辑分账

## 业务意图 → 事件对照

纯前端展示 + 只读 GET，无新事件。
