# 功能意图：租户订单列表按交易单号 / 商户单号查询

## 背景与目标

租户成员在 `/tenant/:tenant/billing/orders/` 用微信支付凭证上的交易单号或商户单号定位本租户订单。

## 范围与边界

- 范围内：列表查询 UI；既有 `GET /api/tenant/{tid}/billing/orders/?order_number=`。
- 范围外：管理端跨租户查单、微信 QueryOrder 兜底、模糊搜索。

## 约束与风险

- 必须 `tenant_id` 隔离，禁止查到他租户订单。
- 日志不得打印完整单号。

## 验收标准

1. 页面有「交易单号」「商户单号」输入与查询/清空。
2. 查询请求带 `order_number`，仅返回本租户匹配订单。
3. 空查询保持原列表（不带 `order_number`）。
