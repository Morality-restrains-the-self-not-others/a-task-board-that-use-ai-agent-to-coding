# 功能意图：推荐资格卡注明微信分账须有效期内手动确认

## 意图

已登录用户打开 `/profile/referral/` 的「推荐资格」卡片时，能看到微信支付个人分账须在微信服务通知有效期内手动点击确认的说明；逾期未确认则该笔分账关闭、无法补分。

## 角色

- 已登录用户（有无推荐资格均可）

## 行为

1. 「推荐资格」卡片在未申请 / 审批中 / 已获资格 / 已过期 / 被拒绝各状态下均展示同一说明。
2. 文案须同时覆盖：须本人在微信内点击、有有效期、逾期无法分账。
3. 不新增 API、不改变申请/审批/分账执行逻辑（微信侧强制用户确认，平台无法代点）。

## 非目标

- 代用户确认微信分账、查询微信确认状态、自动重发服务通知。
- 修改分成比例或资格申请字段。

## 业务意图 → 事件对照

前端只读说明，无新事件。
