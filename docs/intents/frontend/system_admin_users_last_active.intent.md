# 功能意图：超管用户列表展示最后活跃时间

- **日期**: 2026-08-23
- **状态**: 实施中
- **页面**: `/system-admin/users/`

## 背景与目标

超管在用户表中需要看到账号最近一次认证/会话激活时间，而不是只看注册日。

## 范围与边界

- 范围内：活跃/已归档 tab，「注册时间」后新增「最后活跃时间」列；数据来自列表 API `last_login`。
- 范围外：按活跃时间排序/筛选；每请求打点；推荐码申请 tab。

## 约束与风险

- `last_login` 为空显示 —。
- 展示含时分（不只日期）。
- 只读列。

## 验收标准

1. 表头在「注册时间」后有「最后活跃时间」。
2. 有 `last_login` 时单元格显示本地化日期时间。
3. 无值显示 —。
4. 空列表 colspan 覆盖全部列。
