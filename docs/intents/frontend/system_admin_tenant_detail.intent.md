# 功能意图：系统管理租户详情页

- **日期**: 2026-08-25
- **状态**: 已交付
- **页面**: `/system-admin/tenants/:tenantId/`
- **入口**: `/system-admin/users/?tab=tenants` 表格「名称」列

## 背景与目标

超管从租户目录点击公司名称，进入只读详情，查看剩余资源、工作空间、订单。

## 范围与边界

- 范围内：真实 `<a href>`、详情三块只读展示、错误 `data-traceId`、返回租户 Tab。
- 范围外：模拟登录、编辑公司、成员、购买、写操作。

## 约束

- 元规则 49：禁止 `@click.prevent` + `router.push` 冒充链接。
- 元规则 24：请求失败错误节点带 `data-traceId`。
- 元规则 52：纯导航 `Anti-Replay-OK: real href`。

## 验收标准

1. 有名称的行渲染为指向 `/system-admin/tenants/{id}/` 的 `<a>`，可见文本为公司名。
2. 详情页展示配额卡片、工作空间表、订单表（或对应空态/错误）。
3. 非平台员工 API 403；未知租户 header 404。
