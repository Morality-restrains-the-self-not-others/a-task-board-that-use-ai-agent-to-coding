# 前端：开放式邀请链接

- **状态:** accepted
- **日期**: 2026-08-29
- **设计:** `docs/superpowers/specs/2026-08-29-open-invite-link-design.md`

## 用户故事

作为拥有成员管理权限的租户管理员，我在「邀请人」页生成复制链接时，希望能选择开放式链接，把同一个 URL 发给多人，让他们各自加入公司。

## 验收标准

1. 「复制邀请链接」可选单次 / 开放；默认单次。
2. 开放时成员名称不强制；可填最多人数（空=不限）。
3. 文案不再写「只能使用一次」（开放模式）。
4. 待处理列表显示已用/上限。
5. 生成按钮有 clickGuard + Idempotency-Key。

## 业务事件

创建仍走既有 INVITATION_CREATED（服务端）。前端无独立事件。纯 UI 状态无对应 MQ 事件。
