# 功能意图：管理端待开通队列与租户等待开通文案

## 背景与目标

GitLab 磁盘改为超管手动开通后，管理端必须能列出待开通租户，而不是只靠手填 ID。租户连接页继续展示「等待管理员开通实施」，且刷新页面不能把状态变成已开通。

## 范围与边界

- 范围内：`SystemAdminGitlabTenantPanel` 待开通列表；连接页 pending 文案保持
- 范围外：购买页改价；赠送页

## 约束与风险

- 列表来自 system-admin API，租户不可见
- 「开通实施」按钮保持既有 clickGuard + Idempotency-Key
- 无服务端新事件（事件在后端意图）

## 验收标准

1. 管理端 GitLab 租户资源区展示 pending_admin 队列
2. 点队列行填入租户 ID 与 region，可点开通实施
3. 连接页 `provisioning_status=pending_admin` 仍显示等待开通，不出现「已开通」
