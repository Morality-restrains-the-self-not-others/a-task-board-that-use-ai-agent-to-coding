# 前端：租户邀请链接有效期加长

- **状态:** accepted
- **日期**: 2026-08-29
- **页面**: `/tenant/{tenantId}/people/invite/`

## 背景与目标

「复制邀请链接」有效期下拉只有 1/3/7/14/30 天。最长 30 天导致开放/单次链接需要经常轮换。目标：管理员可以把有效期设到最长 365 天，默认 90 天，减少轮换。

## 范围与边界

- 范围内：`InviteLinkMethodPanel` 有效期选项；`PeopleInvite` 表单默认与提交后重置；待处理列表「重新发送」默认有效期。
- 范围外：不新增自定义天数输入；不改邮箱/电话邀请表单布局（仍走同一 `expiration_days` 字段）。
- 无独立 MQ 事件（纯前端枚举 + 默认值）。

## 约束与风险

- 选项必须与后端上限 365 天一致，禁止前端发出 >365。
- 开放链接泄露窗口随有效期变长；仍可用撤销 / `max_uses` 收敛。
- 默认 90 天覆盖「少轮换」；短窗口（1/3/7 天）仍可选。

## 验收标准

1. 有效期下拉选项为 1、3、7、14、30、90、180、365 天。
2. 新建邀请默认选中 90 天。
3. 发送成功后表单重置仍为 90 天。
4. 重新发送邀请请求体 `expiration_days` 为 90（不再硬编码 7）。
