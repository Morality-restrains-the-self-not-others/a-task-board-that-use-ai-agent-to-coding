# 功能意图：订单详情申请开票与发票列表；管理端发票审批 Tab

## 意图

支付成功横幅提供「申请开票」；发票状态与列表展示在该订单下。系统管理「订单与退款」增加发票审批 Tab。

## 角色

- 租户管理员：申请、查看
- 平台员工：审批

## 行为

1. `paid` 且 `total_yuan_cents > 0` 且可申请时显示按钮；金额 ≤ 0 时显示「订单金额为 0 元，无法申请开票」，无按钮；pending 显示「开票审批中」；已开蓝票显示发票号/状态。
2. 申请弹层收集抬头；提交带同步门闩 + `Idempotency-Key`。
3. 错误带 `data-traceId`。
4. 管理端 `?tab=invoice` 列出 pending，approve/reject 同样防重放。
5. 存在待确认冲红（`reverse_pending` / `invoice_reverse_confirm`）时，电子发票区提醒：请在微信卡包于 **72 小时内**确认冲红，逾期冲红将失效；超时显示失效提示。纯展示，`Anti-Replay-OK`。
