# 功能意图：个人推荐页注明分成比例固定 5%

- **日期**: 2026-08-25
- **状态**: 已实施
- **页面**: `/profile/referral/`

## 背景与目标

个人推荐页会展示当前分成比例。该比例已固定为 5%，不再随后台配置调整。用户须看到固定政策，以及打款仍可能受微信商户上限约束。

## 范围与边界

- 范围内：`UserReferral.vue` 资格/申请文案旁，以及 `ReferralStatsPanel.vue` **当前的分账比例**卡片旁的说明。
- 范围外：超管改比例（已删除）；历史订单重算；微信 `max_ratio` 封顶实现。

## 约束与风险

- 说明须始终可见（有资格、无资格申请态、统计卡片均出现）。
- 文案不得再暗示比例将来会由后台调整。

## 验收标准

1. `/profile/referral/` 统计卡标签为「当前的分账比例」，数值来自 stats `referral_rate_display`（后端恒 5%）。
2. 说明文案含「固定为 5%」。
3. `data-testid="referral-rate-change-notice"` 可被测试定位。
4. 无资格申请态与已获资格态都看得到该说明。
