# 功能意图：账单与订单页展示配额来源及订单消耗

## 背景与目标

租户在账单页只看到任务帖合计；订单展开只有行项。需展示赠送/购买剩余，并在订单上查看该订单资源消耗。超管在退款审批弹层也须看到同一笔订单的消耗，才能判断是否批准。

## 范围与边界

- 改 `BillingDashboard.vue`、`BillingOrders.vue`、`OrderDetail.vue`、`SystemAdminRefundPanel.vue`（批准/拒绝弹层复用订单 GET 的 `resource_consumption`）。
- 不新增路由、不改权限码、不新增 HTTP 路径。

## 约束与风险

字段缺失时回退为只显示合计（旧网关兼容）。退款弹层在无消耗时仍展示空态，避免误判为未加载。GitLab 磁盘/流量须按 `resource_consumption` 各 key 展示已发放/已消耗/剩余，禁止在仅购买 GitLab 时用「任务帖已发放 0」占位。
