# 功能意图：赠送资源/订单记录下拉展示租户邮箱与手机号

## 背景与目标

`/system-admin/grant-points` 下拉可见文本仅为「我的公司 ID …」，管理员无法核对账号。模板已预留 `t.phone`/`t.email`，需保证接口有值后可见，并在「已选」摘要中复述。

## 范围与边界

- 范围内：赠送页与订单记录页下拉项、已选摘要；共用联系方式格式化。
- 范围外：改搜索防抖、改权限、非管理端页面。

## 约束与风险

- 空值与「无」不展示，避免假联系方式。
- 管理端展示明文联系方式（本页即用于核对账号）；日志/错误不得回显完整手机号。

## 验收标准

- 下拉每项：公司名、ID、有则显示手机与邮箱。
- 已选摘要同样显示可用联系方式。
- 无联系方式时不出现空白第二行。

## 实施计划

1. `tenantOptionContact.js` 抽格式化并单测。
2. GrantPoints / OrderListPanel 使用该格式化。
3. 赠送页下拉单测断言可见文本含邮箱/手机。
