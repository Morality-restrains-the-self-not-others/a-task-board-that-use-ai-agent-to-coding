# 基准分支候选：按时间排序且下拉固定在输入框下方 — 测试意图

## 测试目标

验证基准分支（及同弹窗同类建议下拉）按时间降序展示，且浮层始终在输入框下方；自由输入仍可用。

## 测试分层

| 层 | 覆盖 |
|----|------|
| 单元（Go） | GitLab/Bitbucket/GitHub 分支解析后按更新时间降序；无时间戳时保持原序 |
| 单元（前端） | SuggestInput：打开在下方、过滤、点选、双击关闭、自由输入 |
| 组件 | CreateTask 基准分支使用自定义下拉而非 datalist；选中后写入 model |

## 用例矩阵

| ID | 场景 | 期望 |
|----|------|------|
| T1 | GitLab 返回带 `committed_date` 的分支 | 新→旧顺序写入 `branches` |
| T2 | 无时间戳分支列表 | 返回顺序与输入一致 |
| T3 | 焦点打开 SuggestInput | 下拉存在且 `top` 相对输入框为下方（`top-full` / 不在上方） |
| T4 | 输入关键字 | 仅展示匹配候选 |
| T5 | 点选候选 | model 更新且下拉关闭 |
| T6 | 手输非候选值 | 允许且提交路径不丢值 |
| T7 | 双击触发器 | 下拉收起 |
| T8 | Teleport 下拉层级 | `style.zIndex` > 10000（高于 modal 内容层） |
| T9 | 焦点时 options 空、随后异步写入 | 仍展示下拉且候选正确 |

## 通过标准

- 上述单元/组件测试全绿。
- 无新增对原生 `datalist` 的基准分支依赖（创建任务路径）。
- 创建任务弹窗内点击基准分支：网络返回分支后列表可见（不被 modal 遮罩挡住）。
