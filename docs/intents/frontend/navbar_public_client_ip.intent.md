# 功能意图：导航栏展示用户公网 IP

## 用户故事

作为已登录用户，我希望在导航栏用户昵称下方看到自己当前的公网 IP，以便确认平台所见的出口地址（例如排障、白名单配置）。

## 验收标准

1. 已登录时，导航栏账号区域在昵称正下方展示公网 IP（等宽小号字）。
2. IP 来源于平台边缘对当前请求解析的客户端地址（`X-Forwarded-For` 从右跳过 RFC1918 / `X-Real-IP` / `RemoteAddr`），经 `GET /api/accounts/users/client-ip/` 返回。
3. IP 拉取失败时不阻断导航栏其它功能；昵称区域仍可用，仅不显示 IP 行。
4. 未登录时不展示该区域（与既有账号切换器一致）。
5. Swagger（taskAuth OpenAPI）可见该接口。

## 范围

- taskAuth `client-ip` API + OpenAPI
- taskGateway 路由（优先于 `/api/accounts/users/*`）
- 前端 `AccountSwitcherDropdown` 展示与 `publicClientIp` 工具
