# 登录页「记住我」回填账号密码

## 意图
用户在 `/auth/login/`（及管理员登录）勾选「记住我」并成功登录后，本机应持久化账号标识与密码（密码类方式）；下次打开登录页自动回填，无需重复输入。取消勾选并成功登录后清除已存凭据。

## 范围
- 邮箱+密码：记住邮箱与密码
- 手机号+密码：记住区号、本地号与密码
- 短信验证码：仅记住手机号（不存验证码）
- 访问令牌：仅记住账号（不存 token）

## 非目标
- 不延长服务端会话 Cookie（与「保持登录」不同）
- 不将明文密码写入日志或后端

## 验收
1. 勾选记住我 → 登录成功 → 登出再进登录页：字段已填且记住我仍勾选
2. 取消勾选 → 登录成功 → 再进登录页：字段为空
