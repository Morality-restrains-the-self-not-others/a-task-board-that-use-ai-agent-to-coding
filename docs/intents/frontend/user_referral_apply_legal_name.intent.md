# 功能意图：申请推荐资格须填写个人名称

## 意图

已登录用户申请推荐资格时必须填写个人名称，并看到「填错将导致后续微信分账失败」的说明。

## 角色

- 已登录用户（申请）
- 系统管理员（审批列表可见该名称）

## 行为

1. 申请表「个人名称」必填，未填或不足 2 字时提交按钮不可用。
2. 名称旁警示：须与微信实名认证姓名一致；填错会导致分账失败，无法补分。
3. 提交 `POST /api/accounts/users/referral-codes/apply/` 带 `legal_name`。
4. 后端拒绝空名称；通过后写入申请记录并在添加分账接收方/请求分账时传给微信。

## 非目标

- 代用户改微信实名、事后更正名称流程、平台代点确认。

## 业务意图 → 事件对照

无新事件（同一申请提交）。
