# 意图：Chrome 插件指针选择支持相邻兄弟多选

## 背景

`taskChromePlugin` 页内悬浮面板的指针选择器此前仅支持单元素。列表（`ul/ol`、卡片行、表格行等）场景下，用户常需对一段连续兄弟节点统一描述调整期望。

## 意图

在指针选择模式下，允许用户通过 **Shift+点击** 在同一父节点下选择一段**连续相邻**的兄弟节点，并将多选快照（标签、区间选择器、兄弟数量、可见文本摘要）写入任务描述调整块；普通点击单选行为保持不变。

## 非目标

- 不支持跨父节点、非连续、或任意多点离散选择
- 不引入拖拽框选或「一键全选列表」
- 不新增后端 API

## 业务意图 → 事件对照

| 业务意图 | 领域事件 | MQ Topic | 说明 |
|----------|----------|----------|------|
| Shift 相邻兄弟多选写入任务描述块 | （无） | — | **无对应事件**：纯前端 Chrome 插件交互，不投递服务端业务事件 |

## 验收要点

1. Shift 锚定 + 同父终点完成区间；非兄弟重置锚点
2. 描述含 `兄弟区间` 与区间 CSS 选择器
3. `taskChromePlugin` 下 `npm test` 通过
