# 功能意图：系统管理员用户页「租户」Tab

- **日期**: 2026-08-25
- **状态**: 已实施
- **页面**: `/system-admin/users/`

## 背景与目标

超管在用户列表页需要直接浏览全部租户公司，而不是只在赠送/订单下拉里搜索。

## 范围与边界

- 范围内：Tab「租户」、`?tab=tenants`、租户表格（ID/名称/创建者/邮箱/手机/创建时间）、搜索与分页。
- 范围外：进入租户工作台、编辑公司、成员管理、替换 tenant-options 下拉。

## 约束与风险

- 与推荐码申请 Tab 一样，切到本 Tab 不请求用户列表。
- 只读；刷新/搜索 Anti-Replay-OK。
- 错误展示须带 `data-traceId`。
- `SystemAdminUsers.vue` 不得超过 500 行。

## 验收标准

1. Tab 栏可见文本含「活跃用户 已归档 租户 推荐码申请」。
2. 点击「租户」展示租户面板，用户表隐藏。
3. 深链 `?tab=tenants` 直接打开该 Tab。
4. 有数据时表格含公司 id 与 name；无数据时空态。
