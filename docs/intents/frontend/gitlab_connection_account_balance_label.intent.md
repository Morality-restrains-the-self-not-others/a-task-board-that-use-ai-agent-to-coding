# 功能意图：租户侧不展示可花现金余额

## 背景与目标

产品模型：用户**没有**可花现金钱包。下单支付后直接发放资源配额
（任务帖 / GitLab 磁盘 / 流量），不存在充值后在系统中留存现金。

上一版曾把 GitLab 连接页 `gitlab-balance-points` 标成「账户余额」，
仍在暗示用户有一笔可花的 `billing_account.balance`。本意图改为
**租户 UI 不再展示该现金字段**。

## 范围与边界

- 范围内：GitLab 连接页内建资源区；账单首页「冻结金额」现金行
- 范围外：系统管理退款审批冻结列；库列 `billing_account.balance`
  （内部账本/退款冻结可保留，不向租户展示为可花余额）

## 约束与风险

- 删除展示，不保留双路径
- 磁盘/流量单价（元/GB）仍展示，那是价目而非钱包
- 购买入口仍是「购买资源」订单，不走充值入钱包

## 验收标准

1. GitLab 连接页不存在 `gitlab-balance-points`，`dt` 不含「账户余额」
2. 磁盘/流量配额与单价标签仍在
3. 账单首页即使 `frozen_balance > 0` 也不展示「冻结金额」

## 实施计划

1. 删除 GitLab 页现金行与 `balanceYuanCents`
2. 删除账单首页冻结现金行
3. 单测断言上述节点不存在

## 变更记录

- 2026-08-22：相对「账户余额」标签版，改为不向租户展示现金钱包。
