# 意图：创建任务「任务类型」与工作区可选值

## 业务意图 → 事件对照

**无对应事件**：任务类型为任务字段扩展与工作区配置；创建/更新仍走既有 `todos` POST/PUT，不新增 MQ 事件。

| 业务意图 | 事件名（过去式） | 发布点 | 消费者/副作用 | 例外理由 |
|---------|----------------|--------|--------------|---------|
| 任务类型可选值配置 | — | — | — | 工作区配置读写，无新增领域事件 |
| 创建/编辑任务选择任务类型 | — | — | — | 写入既有任务聚合字段 `task_kind`，无新事件 |

## 功能意图

1. 创建/编辑任务表单提供「任务类型」下拉，可选值来自当前工作区。
2. 工作区未配置时默认可选值为 `bug-fix`、`feature`。
3. 工作区设置中可自定义可选值列表（每工作区独立）。
4. 选中值持久化为任务字段 `task_kind`（与交付物类别 `deliverable_obj_id` 分离）。
