# 意图：页内浮窗顶部 × 关闭浮窗

## 背景

页内浮窗打开后，用户缺少面板上明确的关闭控件。× 只应收起浮窗，右下角悬浮球保持可见；隐藏悬浮球走扩展弹窗「显示悬浮球」开关。

## 意图

1. 悬浮面板 header 右侧展示 × 按钮（`#taskplugin-float-close`）。
2. 点击 × 仅调用收起面板（`hideFloatPanel`），不隐藏悬浮球，不改 `floatBallEnabled`。
3. 扩展弹窗顶部常显「显示悬浮球」开关（登录与未登录均可）；各页经 storage `onChanged` 同步显隐。

## 非目标

- 不改变扩展弹窗「显示悬浮球」开关语义
- 不新增服务端 API / 领域事件
- 不删除 FAB 点击切换面板的既有行为
