# 功能意图：订单状态筛选与徽章统一中文

- **日期**: 2026-08-23
- **状态**: 已实施
- **页面**: `/system-admin/order-records/`、租户 `/billing/orders/`、订单详情

## 背景与目标

超管订单记录页状态筛选只有「全部 / 待支付 / 已支付 / 已取消 / 已过期」，缺少「已退款」；表格状态徽章对 `refunded` 回退为英文原值。根因是超管列表与租户列表各自维护状态文案，后者已含 `refunded`，前者漏同步。

目标：订单状态文案与筛选项以 `billingOrderDisplay.js` 为唯一来源，筛选含「已退款」，徽章统一中文。

## 范围与边界

- 范围内：超管订单列表筛选与徽章、租户订单列表筛选、订单详情状态文案。
- 范围外：退款申请状态、分账状态、KYC/邀请等其它业务状态；后端订单状态枚举（已有 `refunded`）。

## 验收标准

1. 超管订单记录页状态筛选出现「已退款」，点击后请求带 `status=refunded`。
2. 订单状态 `refunded` 徽章显示「已退款」，不显示 `refunded`。
3. 租户订单列表筛选同样含「已退款」。
4. 订单详情页状态显示「已退款」。
