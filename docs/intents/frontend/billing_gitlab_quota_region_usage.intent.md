# 功能意图：账单页 GitLab 磁盘/流量按区域展示已用量

## 背景与目标

账单「资源配额」把 GitLab 磁盘/流量做成租户级两张汇总卡，看不出区域、也看不出已用。改为按区域分卡，主数字为已用 / 配额。

## 范围与边界

- 范围内：`BillingDashboard` 资源配额区、`GET .../billing/quotas/` 列表项 used 字段的前端消费
- 范围外：新 API、用量实时轮询、购买/赠送流程、GitLab 设置页（已有按区已用）

## 约束与风险

- 只读 GET；禁止为刷新用量加 `setInterval`
- 区域名用 `region_name`，缺省 `region` slug
- used 缺失视为 0（尚未上报）
- 有 `gitlab_resources[]` 时不得再展示无区域汇总 GitLab 卡

## 验收标准

1. 多区域：每区可见磁盘卡与流量卡，文案含区域名与 `已用 / 配额`
2. 磁盘卡保留到期日（有则显示）
3. 赠送/购买拆分仍显示
4. 无 `gitlab_resources` 时回退聚合卡，且聚合卡含已用
