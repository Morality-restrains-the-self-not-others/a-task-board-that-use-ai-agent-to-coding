# 功能意图：工作面板任务搜索过滤

## 用户故事

作为已登录的租户成员，我希望在工作面板标题行输入任务编号、标题或负责人，过滤出任务列表，并跳转到对应工作面板或指定任务，以便在看板上下文中快速定位交付物。

## 验收标准

1. 工作面板单行工具栏内（「工作面板」标题与工作空间切换之间）显示任务搜索输入框；顶部导航栏不再挂载该搜索框。机器摘要与操作按钮与标题/搜索同一行（窄屏可换行）。
2. 可按任务编号、标题、负责人、操作员过滤。
3. 结果可跳转对应工作面板（带 workspace）。
4. 结果「打开任务」使用真实 `<a href>` 进入独立任务详情页 `/tenant/{tid}/workspace/{ws}/task-detail/{taskId}/`（禁止对当前工作面板再 `router.push` 同 URL）。
5. 仅返回当前用户有权访问的工作空间内任务（服务端以 `workspaces?mine=1` 为准；无权限工作空间不得出现在结果中；访问校验失败须 fail-closed，不得扫全库）。
6. 未登录不得搜索；指定无权 `workspace_id` 须拒绝。
7. 搜索失败时错误展示带 data-traceId（若有）。
8. 粘贴评论容器名 / 云实例名 `task_<digits>_cmt_<commentId>`（含 `task-task_` 服务前缀、存量双前缀 `task_task_`、`#`）时，命中规范任务 id `task_<digits>`。
9. 粘贴规范评论 id `cmt_<id>` 时，命中该评论所属任务（服务端按 `task_comments.id` 精确匹配，仍受工作空间 ACL 约束）。

## 范围

- taskTaskService `tasks/search` 扩展
- Vue `NavbarTaskSearch` 挂载于 `WorkPanelHeader` 标题行；`Navbar.ui` 不再挂载
- WorkPanel `task_id` 深链
- 不含跨租户、未登录搜索；不含非工作面板页的全局搜索
