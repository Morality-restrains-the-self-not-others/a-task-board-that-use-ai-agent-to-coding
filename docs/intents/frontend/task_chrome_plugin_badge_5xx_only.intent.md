# task_chrome_plugin_badge_5xx_only（功能意图）

## 1. 背景与目标

- 背景：`taskChromePlugin` 可按配置捕获 2xx/3xx/4xx/5xx/Canceled；扩展图标角标与「错误→建任务」示数若计入全部捕获项，会把客户端错误与成功请求混入告警数字。
- 目标：插件任务相关**示数仅包括 HTTP 5xx（500–599）**请求。

## 2. 范围与边界

- 范围内：
  - 扩展工具栏角标（`chrome.action` badge）递增条件
  - 批量捕获 Tab 的「5xx 示数」展示
  - 「错误列表」Tab 列表内容
  - 「批量创建任务」纳入的请求集合与创建中计数
  - `getRecentRequests` 的 `errorsOnly` 过滤
- 范围外：
  - 捕获配置本身仍可勾选非 5xx（用于预览/调试）
  - Popup「请求预览」仍可按过滤器查看全部捕获项

## 3. 行为约定

| 场景 | 计入示数 / 建任务 |
|------|-------------------|
| status 500–599 | 是 |
| 4xx / 2xx / 3xx | 否 |
| Canceled（status=0） | 否 |

## 4. 变更记录

| 2026-07-14 | 示数与批量建任务统一为仅 5xx；捕获可仍含其它状态码 | 用户目标：示数仅含 5xx |
