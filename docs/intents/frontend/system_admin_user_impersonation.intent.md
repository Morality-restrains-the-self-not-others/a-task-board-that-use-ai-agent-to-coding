# 功能意图：用户编辑页「以该用户身份登录」

- **日期**: 2026-08-23
- **状态**: 实施中
- **页面**: `/system-admin/users/` 编辑用户模态框

## 背景与目标

在编辑用户表单增加按钮，经 `user:impersonate` 控制，点击后进入该用户身份的前台，并可退出回到系统管理。

## 范围与边界

- 范围内：编辑模态框与列表行按钮、理由弹窗、防重放、成功跳转、Navbar 模拟横幅与退出、账号中心收信箱。
- 范围外：推荐码申请 tab。

## 验收标准

1. 有 `user:impersonate` 时编辑表单可见按钮「以该用户身份登录」。
2. 无该权限时按钮不渲染。
3. 点击使用同步门闩 + 同一 Idempotency-Key。
4. 成功后浏览器进入目标用户前台（非系统管理页）。若已在模拟同一用户，确认登录仍跳转到该用户前台，而不是停在弹窗错误 `already impersonating`。
5. 模拟期间 Navbar 显示身份提示与退出；退出回到 `/system-admin/users/`。
6. 失败展示带 `data-traceId`。
7. 点击后先弹窗填写理由；取消不发请求。
8. 账号中心可见收信箱，展示代登理由。

## 业务意图 → 事件对照

| 业务意图 | 事件名 | 例外理由 |
|----------|--------|---------|
| 点击模拟登录 | UserImpersonationStarted | 由后端发布 |
| 点击退出模拟 | UserImpersonationStopped | 由后端发布 |
