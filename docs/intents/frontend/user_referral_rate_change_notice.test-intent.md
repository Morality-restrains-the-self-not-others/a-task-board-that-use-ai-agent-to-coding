# 测试意图：个人推荐页分成比例固定说明

## 测试目标

页面在展示当前分成比例时，须说明比例固定为 5%，打款不超过微信商户上限。

## 测试分层

- 前端组件：`UserReferral.rateChangeNotice.test.js`
- 统计面板：`ReferralStatsPanel.test.js`

## 用例矩阵

| ID | 场景 | 期望 |
|----|------|------|
| F1 | 无推荐资格 | 申请文案旁可见 `referral-rate-change-notice`，文案含「固定为 5%」 |
| F2 | 已获推荐资格 | 资格分成文案旁同样可见该说明 |
| T56 | 收益统计展示当前比例 | 标签为「当前的分账比例」；数字旁可见同一说明 |

## 通过标准

上述测例全绿；公网 `/profile/referral/` 硬刷新后可见该说明。
