# 功能意图：项目详情「所属公司」展示公司名称

- **日期**: 2026-08-28
- **状态**: 已实施
- **页面**: `/tenant/:tenant/projects/:id/`

## 背景与目标

项目详情「关联信息 → 所属公司」当前渲染 `project.company`（租户/公司 ID，如 `881024523581812736`）。该字段是 taskProjectService 的归属键，不能改成名称。用户需要看到公司名称。

## 范围与边界

- 范围内：项目详情页「所属公司」展示 taskTenantService `GET /api/tenant/<tid>/accounts/companies/current/` 返回的 `name`。
- 范围外：不改 `project.company` 契约（OAuth catalog 等仍用 ID）；不在 taskProjectService 直查租户表。

## 约束与风险

- 公司名由 accounts/tenant 拥有（单表单服务）。名称拉取失败时展示「未设置」，禁止回退显示 Snowflake ID。
- 名称请求失败不得阻断项目详情主流程。

## 验收标准

1. 「所属公司」展示公司名称，而不是租户 ID。
2. 名称接口失败或名称为空时展示「未设置」，页面其余信息仍可用。
3. `project.company` 仍为公司 ID，供既有 Git OAuth 等逻辑使用。
