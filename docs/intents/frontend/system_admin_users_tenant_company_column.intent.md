# 功能意图：系统管理员用户列表展示所属租户公司

- **日期**: 2026-08-23
- **状态**: 已实施
- **页面**: `/system-admin/users/`

## 背景与目标

超管在用户表中需直接看到每个账号加入了哪些租户公司，而不是只看「租户」角色标记。

## 范围与边界

- 范围内：活跃用户 / 已归档 tab 表格新增「所属租户公司」列；数据来自列表 API `tenant_companies`。
- 范围外：按公司筛选/搜索、编辑用户的公司归属、推荐码申请 tab。

## 约束与风险

- 多家公司用「、」拼接；无名时显示 id；无活跃归属显示 —。
- 只读列，无写操作。

## 验收标准

1. 表头在「邮箱」后有「所属租户公司」。
2. 有活跃公司时单元格显示名称（或多名称拼接）。
3. 无公司时显示 —。
4. 空列表 `colspan` 覆盖全部列。
