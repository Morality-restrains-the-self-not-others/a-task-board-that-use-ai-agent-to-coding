# 功能意图：订单记录页按微信关联账号查询

## 意图

平台员工在系统管理订单记录页可用「微信关联账号」查询资源订单，与交易单号查询并列，无需先选租户。

## 角色

- 系统管理员 / 平台员工

## 行为

1. 查询 Tab：交易单号 | 微信关联账号。
2. 微信 Tab 输入后请求 `GET /api/system-admin/orders/?wechat_account=`，不带 `order_number`。
3. 未命中展示空态；超长/校验失败展示错误且带 `data-traceId`。
4. 成功后 URL 写入 `?wechat_account=`；深链可还原 Tab 并自动查询。

## 非目标

- 不在租户侧订单列表增加该入口。
- 不在表格展示 openid。

## 业务意图 → 事件对照

纯查询，无新领域事件。
