# 交付物分区标题按进度列展示任务数

## 意图

工作面板交付物分区折叠条（`data-alias="deliverable-section-count"`）应展示**各进度列**的任务数量，而非该分区任务总数。

## 验收行为

1. 分区标题右侧按进度体系列顺序显示多项计数（色点 + 数字），与看板纵轴一一对应。
2. 折叠/展开分区时计数仍可见，且与展开后各列 `progress-column-count` 一致。
3. 过滤分区与「其他（未过滤）」分区均按各自任务子集分列统计。
4. 无进度列时不渲染计数区。
