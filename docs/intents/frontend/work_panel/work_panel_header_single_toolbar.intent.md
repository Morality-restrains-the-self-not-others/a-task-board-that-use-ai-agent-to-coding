# 工作面板顶栏合并为单行工具栏

- **日期**: 2026-09-02
- **状态**: 已实施

## 背景与目标

云端开发工作面板（`/tenant/{tid}/work-panel`）顶部原先两行：标题/搜索/自动调度/工作空间，与机器节点摘要/创建任务/人小组/筛选。用户要求合并为一行，减少看板上方占用。

## 范围与边界

- 范围内：`WorkPanelHeader.vue` 把 `header-title-row` 与 `header-summary-row` 放入同一 `header-toolbar-row`（`flex flex-wrap`），视觉上默认单行；窄屏允许换行。
- 范围内：工作空间切换并入右侧 `header-actions-row`（与创建任务、人/小组、筛选一起 `ml-auto`）。
- 范围内：保留两路 `data-traceId` 隔离（标题区 = 工作空间列表失败；摘要区 = 机器摘要轮询失败）。
- 范围外：不改搜索 API、机器摘要轮询、筛选语义、创建任务流程。

## 约束与风险

- 搜索组件根节点带 `flex-1`，合并后须固定宽度包裹，避免 shrink-wrap 把工具栏撑成两截。
- Playwright `WorkPanel.auto-schedule-link` 仍要求搜索框 → 自动调度安排 → 工作空间选择器的 x 递增且与搜索同一行。

## 验收标准

1. `data-alias=header-toolbar-row` 存在，class 含 `flex flex-wrap`、不含 `flex-col`。
2. `header-title-row` 与 `header-summary-row` 为其直接子节点，均无 `w-full` / 摘要区无 `mt-2`。
3. 工具栏内可见「工作面板」、任务搜索、机器节点摘要、创建任务、人/小组、筛选；有 tenant 时工作空间切换在右侧操作区。
4. 工作空间加载失败仍把 `data-traceId` 挂在 `header-title-row`；机器摘要轮询失败仍挂在 `header-summary-row`。
5. 任务搜索仍位于「工作面板」标题与工作空间切换之间（文档序与桌面 x 序）。
