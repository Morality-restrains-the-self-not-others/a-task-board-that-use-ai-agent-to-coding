# 意图：项目详情显示内部仓库磁盘占用

## 用户意图

在项目详情页的 Git 仓库列表中，对平台**内部仓库**显示其占用的磁盘空间；**外部仓库**不显示磁盘占用。

## 业务规则

1. 内部仓 = OAuth catalog 匹配 `gitlab:gitlab-local`（平台 gitService）。
2. 磁盘占用单位为字节源数据，UI 以 B/KB/MB/GB 展示。
3. 无法获取大小时：内部仓也不展示错误数字（省略徽章）。
4. 外部仓：永不展示磁盘占用 UI。

## 业务意图 → 事件对照

**无对应事件**：纯查询例外，只读 enrich 详情字段，无业务状态变更，不投递领域事件。

| 业务意图 | 事件名（过去式） | 发布点 | 消费者/副作用 | 例外理由 |
|---------|----------------|--------|--------------|---------|
| 项目详情展示内部仓磁盘占用 | — | — | — | 纯查询例外，无服务端业务状态变更 |

## 验收

- 内部仓有 statistics → 可见「磁盘：…」徽章（`data-testid=git-repo-disk-size`）。
- 外部仓 → 无该 testid。
