- 2026-07-12：首次记录。任务详情/创建任务「目标分支」下拉改为关联仓库分支交集。

## 功能意图

1. 编辑分支策略时，先拉取任务关联项目下所有仓库的分支列表。
2. 「目标分支」下拉仅展示各仓库**共有**的分支名称。
3. 创建任务弹窗与任务详情编辑行为一致。
4. 2026-07-12 补充：工作分支/目标分支各自仅保留一个输入框（模版并入 datalist，不再单独展示模板下拉）。

## 验收要点

- 两仓同有 `main`/`develop`、仅一仓有 `feature/x` → 下拉仅 `develop`、`main`（及其它共有名）。
- 仅一仓 → 下拉为该仓全部分支。
- 无关联仓库或拉取失败导致无法形成交集 → 提示 + 可手动输入。
