# 功能意图：导航栏多账号切换

## 用户故事

作为已登录用户，我希望在导航栏昵称处打开下拉菜单，在本机已登录的多个账号间切换当前激活身份，以便不反复完整登出/登入即可使用不同账号。

## 验收标准

1. 单击昵称区域展开账号下拉；双击收起。
2. 下拉展示本机已保存账号列表，当前激活账号有标识。
3. 选择另一账号后，系统校验其 token 并切换激活身份，页面以新账号身份工作。
4. 可通过「添加账号」登录另一账号并加入列表（最多 5 个）。
5. 「退出当前」登出激活账号并从列表移除；若还有其它账号则激活其一，否则进入登录页。
6. 无效 token 不可切换成功，并提示重新登录。
7. 在 `/tenant/{id}/...` 页面切换或添加账号时，不得保留原租户 URL（应落到个人中心或首页），避免新账号对原租户接口批量 403/400。
8. 直接打开无权访问的租户 work-panel 时，前端应提示并跳转，不继续打业务接口。
9. 从账号 A 切换到账号 B 后，B 不得看到 A 的私有资源：须清除旧 `sessionid`；业务 API 在同时携带 Session 与 Token 时以 Token 身份为准；`/me/` 的 path `user_id` 须与认证主体一致。
10. `activate-session`（及登录 enrich）成功后，须向浏览器写入目标用户的 HttpOnly `sessionid`（与表单登录 cookie 属性一致），收敛纯 Session 请求。

## 范围

- 前端 Navbar / Login / savedAccounts 存储
- taskAuth `activate-session` API（含 Set-Cookie sessionid）
- Django enrich-login 返回 `session_key`
- WorkPanel 租户访问守卫
- Django DRF 鉴权顺序与 `me()` 路径校验（隔离加固）
- Playwright 跨账号隔离 E2E
- 不含跨设备同步
