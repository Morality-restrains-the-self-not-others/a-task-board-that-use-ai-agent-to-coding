# 功能意图：编辑用户手机号占用时在表单内提示

- **日期**: 2026-08-28
- **状态**: 已实施
- **页面**: `/system-admin/users/` 编辑用户模态框

## 背景与目标

保存占用中的手机号时接口若返回 409，编辑弹窗必须留在页面并在「手机号」字段下展示原因，禁止静默关闭。

## 范围与边界

- 范围内：`handleEditUser` / `handleAddUser` 解析 `phone_taken` / `email_taken`，内联错误 + `data-traceId`。
- 范围外：归档冲突 toast。

## 验收标准

1. 409 后弹窗仍打开，`#edit-phone` 仍可见。
2. `[data-testid=edit-phone-error]` 展示服务端 detail，`data-traceId` 取自响应。

## 业务意图 → 事件对照

| 业务意图 | 事件名 | 例外理由 |
|----------|--------|---------|
| 展示编辑失败 | （无） | 纯前端错误展示 |
