# 功能意图：工作面板任务卡创建人可读化与评论展开

## 用户故事

作为工作面板用户，我希望任务卡上的创建人标识含义清晰，并能通过点击「评论」直接展开评论区，以便理解任务归属并快速查看/发表评论。

## 验收标准

1. 任务卡左侧不再仅展示难懂的首字母头像（如缺失用户名时的「U」）；须有「创建人」文案，并展示用户名（缺失时为「未知用户」）。
2. 任务卡上不出现「添加评论」独立入口文案。
3. 点击「评论」后，下方出现评论区（列表或「暂无评论」）及评论输入框；再次点击可收起。

## 范围

- 前端 `front_project/app/src/components/TaskDetail.vue`（看板任务卡）
- 不含评论 API / 权限变更
