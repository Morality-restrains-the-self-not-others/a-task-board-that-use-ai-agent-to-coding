# 意图：创建任务结构化可选字段

## 业务意图 → 事件对照

**无对应事件**：纯前端表单增强；结构化字段在提交前拼入既有 `description`，不新增服务端业务状态变更或 MQ 契约。任务创建仍走既有 `todos` POST/PUT 路径。

| 业务意图 | 事件名（过去式） | 发布点 | 消费者/副作用 | 例外理由 |
|---------|----------------|--------|--------------|---------|
| 创建任务结构化可选字段 | — | — | — | 纯前端拼装 description，无新增领域事件 |

## 业务意图

租户用户在工作台创建任务时，可用可选结构化字段描述背景、问题、期望修改、目标位置、行为约束、依赖策略与验证方式，以便后续 Agent/auto_run 更准确理解任务。

## 成功路径

1. 用户打开工作台 → 创建任务。
2. （可选）填写结构化字段与任务描述。
3. 提交后任务 `description` 含对应 Markdown 段落（或仅自由描述）。
4. auto_run 时容器侧仍通过既有 title+description 组装首指令（无新事件契约）。

## 权限

与既有「创建/编辑工作区任务」一致；不新增角色或 API 权限点。
