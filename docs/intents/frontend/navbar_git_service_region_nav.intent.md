# 功能意图：导航栏「代码仓库」按租户仓库资源跳转

## 背景与目标

导航栏「代码仓库」按租户已开通/获赠的 GitLab 区域决定行为：**有仓库资源则可跳转到对应区域 GitLab；无资源且列表已成功拉取时跳转 `/pricing/`**（转化购买）。拉取失败或尚未返回时 fail-open 留在当前页，避免接口故障误送价格页。

## 范围与边界

- **范围内**：`Navbar.logic` 拉取当前租户已开通/已赠送的 GitLab 区域列表；`Navbar.ui` 无资源且 `ready` 时 `<a>` 指向 `/pricing/`（保留 `accessCode`），单区域直链，多区域下拉；`GET .../billing/gitlab-resources/` 无 `region` 时附带 `resources[]`。
- **范围外**：不改购买/赠送/开通流水；不改自建 GitLab OAuth；不按 VIP 拦截跳转。

## 约束与风险

- 导航必须是真实 `<a href>`（禁止 click.prevent + router.push）。
- 下拉：单击展开、双击收起；菜单项 `target=_blank` + `rel=noopener noreferrer`。
- 纯查询，无 MQ。
- 不泄漏 `admin_private_token`。

## 验收标准

1. 租户无仓库资源且列表 `ready`：「代码仓库」href 为 `/pricing/`（可带 `accessCode`），真实 `<a>`。
2. 列表 `unknown`/`error`：href 为当前页，不跳转 `/pricing/`（fail-open）。
3. 普通会员获赠 ≥1 区域资源：可跳转到该区域 `gitlab_web_url`（不因 `normal` 去价格页）。
4. ≥2 个区域：下拉列出各区域名称，每项真实外链。
5. VIP1 角标仅 `membershipTier===vip1` 时显示；无资源已就绪时仍去价格页。
6. 未登录不显示该入口。

## 业务意图 → 事件对照

**无对应事件（纯查询/纯前端导航例外）**：不改变计费或开通状态。
