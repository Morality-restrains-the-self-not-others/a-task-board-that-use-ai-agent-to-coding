# Intent: runAll 进度条日志须手动清空才消失

## 背景与目标

http://10.2.150.68:9999/ 全部重启 / 精准编译重启等批量操作结束后，进度条及错误日志会在数秒内自动淡出。运维来不及对照失败列表。目标：完成后面板保持可见，仅点击「清空」后才关闭。

## 范围与边界

- **范围内**：`runAll/src/status_ui/` 进度面板（`#start-all-progress-panel`）的完成态展示与关闭。
- **范围外**：服务 tee 日志 `POST /api/logs/clear`；开发工具日志清空；不改 SSE 后端契约。

## 约束与风险

- 新一轮批量操作开始时仍由 `showProgress` 重置面板（不清空按钮不等于禁止新操作）。
- SSE `phase=idle` 表示当前无进行中的 run，不得当作用户关闭意图。
- 「清空」为纯前端关闭，无写接口（Anti-Replay-OK）。

## 验收标准

1. 批量操作 `done` 后进度面板保持 `is-active`，不因 3s/5s/10s 定时器或 SSE idle 自动移除。
2. 完成后显示「清空」按钮；点击后面板关闭（去掉 `is-active`）。
3. 单服务启停/重启同样不自动隐藏。

## 实施计划

1. 单测锁定：禁止 auto-hide timer；idle 不得 `remove('is-active')`；组装页含清空按钮。
2. 去掉 `_progressAutoHideTimer` 的 fade-out；idle 处理改为保留面板。
3. 增加 `dismissProgressPanel` 与 `#prog-clear-logs-btn`。
