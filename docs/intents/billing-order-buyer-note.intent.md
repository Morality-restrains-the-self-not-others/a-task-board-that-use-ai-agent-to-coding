# 下单施工留言（非自动发货资源）

## 意图

租户创建资源订单时，若购买需人工履约的资源（当前 GitLab 磁盘），可填写可选施工留言，供平台开通人员阅读。

## 验收

1. 购物车含 `gitlab_disk` 时下单页出现选填留言（≤2000 字）
2. POST `buyer_note` 写入 `billing_resource_order.buyer_note`
3. 仅自动发货 SKU 提交非空留言 → 400
4. 租户详情与超管订单展开可见留言；错误带 `data-traceId`
5. 日志不含留言正文
