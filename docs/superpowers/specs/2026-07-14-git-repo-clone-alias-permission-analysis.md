# 角色权限分析：Git 仓库克隆别名

日期：2026-07-14

## 结论

不新增独立权限点。别名随项目 create/update 写入，沿用既有项目写权限。

| 操作 | 角色 | 判定 |
|------|------|------|
| 创建项目写 clone_alias | 有项目创建权的租户成员 | 同现有 create |
| 编辑项目改 clone_alias | 有项目编辑权 | 同现有 PATCH |
| 读取 git_repo_entries | 有项目/任务读权 | 同现有详情/task-detail |
| 容器消费别名 | server-container-token | 同现有 task-detail |

## 风险

- 别名不参与鉴权；恶意别名仅影响本地目录名（sanitize 限制字符集）
- 无跨租户泄漏面变化
