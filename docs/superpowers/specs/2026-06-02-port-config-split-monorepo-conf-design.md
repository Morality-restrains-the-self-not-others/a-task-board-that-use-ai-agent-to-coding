> 日期：2026-06-02  
> 状态：**已实施（Phase 3 完成）** — `conf/` 树、sync、全仓直读 YAML；`port_config.json` / `port_config.test.json` 已删除  
> 替代：`task2app/conf/port_config.json` 单体 JSON  
> 关联：`task2app/conf/port_config.json.md`、`value-stream.yaml`（git-oauth / domain-events 步骤）

## 1. 目标与完成标准

| 标准 | 说明 |
|------|------|
| 配置根 | 权威配置位于 **monorepo 根** `<ram-mount>/conf/<app>/`，不再使用 `task2app/conf/port_config.json` |
| 直读 | 各服务/应用**只读**自己目录下的 YAML（+ 本目录 sync 碎片）；删除 `read_port_config()` 等 JSON 聚合层 |
| 跨应用一致 | 通过 `sync.manifest.yaml` + `sync.sh` 从权威 `config.yaml` 复制键到 `conf/<app>/<peer>.yaml` 碎片 |
| 碎片治理 | **碎片仅由 sync 生成，禁止手改**（见 §4） |
| taskEvents | 领域事件配置为 `conf/domain-events/config.yaml`（全局）+ `conf/domain-events/<event>/config.yaml`（按事件） |
| 测试配置 | `conf/core/django/config.test.yaml` **完全替代** `conf/port_config.test.json` 与 `task2app/conf/port_config.test.json`；迁移后**删除**上述 JSON 及 `.ai` 伴读 |

## 4. 碎片文件治理（仅 sync 生成）

1. 每个 `conf/<app>/<peer>.yaml`（及非 `config*` 的 yaml）文件**头部**必须包含：

   ```yaml
   # GENERATED by conf/<app>/sync.sh — DO NOT EDIT
   # source: conf/<owner>/config.yaml
   # synced_at: <ISO8601>
   ```

2. **禁止手改**：CI / `runAll doctor` / pre-commit 可选检查：
   - 碎片缺少 GENERATED 标记 → fail
   - `config.yaml` 变更但碎片 hash 未更新 → fail（提示运行 `scripts/conf-sync-all.sh`）

3. **`.gitignore` 不忽略碎片**（碎片随 sync 提交），保证克隆即用；机密仍在各 app 的 `config.local.yaml`（已 ignore）。

4. `sync.manifest.yaml` 示例：

   ```yaml
   version: "1"
   fragments:
     - from: ../task-auth/config.yaml
       to: task-auth.yaml
       pick: [host, port, internalSecret]
     - from: ../django/config.yaml
       to: django.yaml
       pick: [host, port, allowedHost]
   ```

5. 支持 `pick` 项 `{ from: internalApiBase, as: djangoInternalApiBase }` 显式重命名。

## 5. `conf/domain-events/<event>/config.yaml`

### 5.1 与现 `port_config.domainEvents` 的映射

| 原 JSON 路径 | 新路径 |
|--------------|--------|
| `domainEvents.transport` / `kafka` / `redis` / `internalSecret` | `conf/domain-events/config.yaml` |
| `domainEvents.consumers.<event>.intents.<intent>` | `conf/domain-events/<event>/config.yaml` → `intents.<intent>` |

### 5.2 单事件文件示例（`user_created`）

```yaml
# conf/domain-events/user_created/config.yaml
intents:
  0_create_company:
    host: 127.0.0.1
    port: 18025
    groupId: task-events-user-created-0-create-company
    events: [USER_CREATED]
  1_send_welcome_email:
    host: 127.0.0.1
    port: 18026
    groupId: task-events-user-created-1-send-welcome-email
    events: [USER_CREATED]
```

### 5.3 taskEvents 加载顺序（实现约定）

对每个 `{event}/{intent}`（`LoadIntent`）：

1. 代码内 `IntentByPath` 默认 port/groupId  
2. **`conf/domain-events/<event>/config.yaml`** 中 `intents.<intent>`（替代原 `intentFromPortConfig` 读 JSON）  
3. **`taskEvents/bin/<event>/<intent>/config.yaml`** 本地 overlay（保留，优先级最高）

全局 transport/redis：`Load()` 读 `conf/domain-events/config.yaml` + `conf/domain-events/django.yaml`（sync 的 internalApiBase）。

**删除**：`task2app/conf/port_config.json` 中整个 `domainEvents.consumers` 树；`intentFromPortConfig` / v3 flat 兼容路径在 Phase 3 移除。

## 7. 运行时加载（直读）摘要

| 消费者 | 读取路径 |
|--------|----------|
| Saas_project | `conf/core/django/config.yaml` + 碎片；settings 按字段显式 `load_peer("task-auth")` 或小型 loader |
| front_project / Vite | `conf/vue/config.yaml` + `django.yaml` |
| gitOauth | `conf/git-oauth/config.yaml` + `providers/*.yaml` |
| taskEvents | `conf/domain-events/config.yaml` + `conf/domain-events/<event>/config.yaml` |
| taskAuth / taskBill / Go sidecars | `conf/<app>/config.yaml` |
| db 脚本 / shell | `yq` 或 `scripts/conf-read.py <app> <key>` |

**优先级**（不变）：环境变量 / `.env_*` > `config.local.yaml` > `config.yaml`；碎片只读；测试再加 `config.test.yaml`。

**Monorepo 根解析**：`FindMonorepoRoot` 标记改为存在 `conf/core/django/config.yaml`；`task2app/paths.conf` 的 `PORT_CONFIG_JSON` 标记 deprecated。
