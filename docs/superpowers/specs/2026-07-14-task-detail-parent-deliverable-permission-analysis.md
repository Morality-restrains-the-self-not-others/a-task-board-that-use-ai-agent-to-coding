## 改动点权限表

| 改动点 | 主体 | 资源层级 | 操作 | 现有检查 | 是否缺失 | 建议 |
|--------|------|----------|------|----------|----------|------|
| UI 展示 parent_task | 已能打开任务详情的成员 | Workspace / Task | read | 详情页既有鉴权 | ✅ | — |
| GET .../todos/{parentId}/ | 同上 | Workspace / Task | read | taskTaskService + 网关租户/工作空间校验 | ✅ | 失败时 UI 回退，不泄露跨租户数据 |
| 修改 parent_task | — | — | write | 本期不做 | ✅ | 不引入编辑入口 |

## IDOR / 越权风险

- 前端仅用当前详情返回的 `parent_task` 发起二次 GET；服务端仍校验 workspace 归属。
- 若上级任务不可读：显示 `ID:{id}` 或「无法加载」，不展示其它租户字段。

无需新增角色或权限粒度。
