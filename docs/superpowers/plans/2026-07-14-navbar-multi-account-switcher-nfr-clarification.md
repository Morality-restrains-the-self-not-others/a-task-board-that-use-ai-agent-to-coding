# NFR 澄清：导航栏多账号切换

**日期**: 2026-07-14  
**默认级别**: L2 Standard；认证相关项 L3

| 类别 | 级别 | 场景 | 度量 |
|------|------|------|------|
| 安全性 | L3 | Token 校验后方可切换；日志脱敏 | 无明文 token 入日志；401/403 正确 |
| 可用性 | L2 | 切换后整页刷新 < 3s（本地） | 手工/冒烟 |
| 可靠性 | L2 | enrich-login 失败返回 502，前端保留原账号 | Go 测试 + 前端错误提示 |
| 可观测性 | L2 | activate-session 记 userId + 结果码 | 结构化日志 |
| 容量 | L2 | 每浏览器最多 5 槽 | 单元测试 |
| 兼容性 | L2 | 异域 Cookie/API 基地址不变 | 回归现有登录 |
| 隐私 | L2 | 槽仅本机；退出删除 token | 代码审查 |

## 领域模型影响

- 无新持久化聚合；AccountSlot 为客户端值对象集合
- ActiveAccount 仍由 Token + userId 表达
