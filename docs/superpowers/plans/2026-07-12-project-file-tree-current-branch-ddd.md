## 概念

| 术语 | 含义 |
|------|------|
| Git 仓库根 | 点击目录对应绝对路径下存在 `.git` |
| 当前工作分支 | 该 workdir 内 `HEAD` 的 `--abbrev-ref` |
| pathspec | 相对仓库根的路径过滤；`null` 表示点击点即为 workdir 根 |

## 领域规则
