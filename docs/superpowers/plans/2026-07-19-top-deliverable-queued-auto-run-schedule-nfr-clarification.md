# NFR：顶层交付物排队自动执行调度节奏

- 日期：2026-07-19
- 默认等级：L2 Standard（goal-mode）

| 类别 | 等级 | 说明 |
|------|------|------|
| 性能 | L2 | Dispatcher 周期 ≤30s；单次扫描 O(成员数) 可接受 MVP |
| 可用性 | L2 | ticker 宕机后重启可恢复；成员状态落库 |
| 安全 | L2→L3 边界 | `started_via=queued_schedule` 仅可信代调；防 IDOR |
| 可观测 | L2 | 结构化日志 + 领域事件含 trace_id |
| 成本 | L2（本功能动机） | 窗外不启服；并发上限硬约束 |
| 一致性 | L2 | 出队与手动启服最终一致即可 |

无金融/支付域，不升 L3 全项。
