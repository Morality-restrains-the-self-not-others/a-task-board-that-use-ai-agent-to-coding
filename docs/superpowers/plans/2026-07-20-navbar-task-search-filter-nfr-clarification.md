# NFR 澄清：导航栏任务搜索过滤

- **日期**: 2026-07-20
- **默认等级**: L2（Standard）

| 类别 | 等级 | 约定 |
|------|------|------|
| 性能 | L2 | 防抖 250ms；limit 默认 20；单次查询目标 P95 < 500ms（本机/小库） |
| 可用性 | L2 | 搜索失败不阻断导航其他链接；错误带 data-traceId |
| 安全 | L2 | 复用 ACL；无新敏感字段落日志（避免打印全量结果） |
| 可观测 | L2 | 前端 console/请求日志保留既有 apiFetch 模式；Go 沿用既有 error log |
| 兼容 | L2 | 旧客户端忽略新增响应字段；无 `assignee_ids` 时行为 = 扩展后的 q 匹配 |
| 无障碍 | L2 | input 有 label/placeholder；下拉键盘 Esc 关闭 |
