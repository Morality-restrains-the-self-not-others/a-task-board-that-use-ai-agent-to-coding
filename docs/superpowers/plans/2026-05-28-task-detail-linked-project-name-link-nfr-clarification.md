# NFR Clarification: 任务详情关联项目名称链接

> Value stream: `docs/superpowers/plans/2026-05-28-task-detail-linked-project-name-link-value-stream.md`

## 适用类别

| 类别 | 等级 | 说明 |
|------|------|------|
| 性能 | L1 最低 | 纯客户端路由，无 API |
| 安全 | L2 标准 | 沿用 `requiresAuth` 与项目详情既有权限 |
| 可用性 | L2 标准 | 链接缺失 ID 时降级为静态文本 |
| 可访问性 | L2 标准 | 链接具备可读 title；键盘可聚焦 |
| 一致性 | L2 标准 | URL 与 `Projects.vue` 列表一致 |

## 质量场景

1. **刺激**: 用户点击关联项目名称 → **响应**: 300ms 内完成 SPA 路由切换（无额外请求）。
2. **刺激**: `project_id` 为空 → **响应**: 显示不可点击徽章，不抛错。
3. **刺激**: 未登录访问 → **响应**: 路由守卫跳转登录（既有行为）。

## 领域模型影响

无 — 纯前端导航，跳过 DDD 实体/聚合变更。

## 跳过项

- 性能压测、国际化、离线 — 不适用。
