# 零额订单禁止开票 — 价值流

设计：`docs/superpowers/specs/2026-08-29-zero-amount-invoice-block-design.md`

本增量挂在既有「租户申请开票 → 管理员登记」价值流上，只增加一条失败出口。

```
租户打开已支付订单详情
  → 金额 > 0？
      否 → 展示「无法申请开票」说明（无 POST）
      是 → 申请开票 → POST invoice-applications
            → 后端再校验 total_yuan_cents > 0
                 否 → 400，不写申请、不发事件
                 是 → 201 pending（既有）
  → 管理员 approve
      → 再校验金额 > 0 后才落蓝票
```

## 最小增量（本会话只交付这一条）

| 增量 | 价值 | 验收 |
|------|------|------|
| I1 零额禁开票 | 避免对 0 元订单申请/开具增值税发票 | T15 / F9 测例绿；按钮在 0 元订单上不可见 |

无后续增量阻塞。
