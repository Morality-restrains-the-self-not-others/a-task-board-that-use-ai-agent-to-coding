# DDD：默认服务器启动配置迁入机器节点策略

## 结论

**纯前端入口迁移，无领域模型 / 聚合 / 仓储 / 领域事件变更。**

| 项 | 说明 |
|----|------|
| 限界上下文 | Cloud / Workspace（既有） |
| 新实体/VO | 无 |
| 新领域事件 | **书面例外**：无服务端业务意图变更，不投递 MQ 事件 |
| 数据所有权 | `server-config-default` 仍属既有云配置 owner 服务 |

## 术语

- **默认服务器启动配置**：租户级、按云平台授权维度的启动预设；项目「快速应用默认模版」的选项源。
- **机器节点策略**：工作空间级启用授权、闲置回收、复用与 @ 模式；本次为其管理入口挂载点。
