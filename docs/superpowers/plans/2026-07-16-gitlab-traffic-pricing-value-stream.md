# GitLab 流量费定价 — 价值流

## 最小价值增量

超管配置「GitLab 流量费」单价 → 新开户/切换套餐锁价 → 租户在计费页看到单价与「同区域内网不计费」说明。

## 步骤

1. 超管打开价格管理，填写流量费（积分/GB）
2. 系统写入套餐列并 sync `billing_unit`
3. 新开户或切换套餐时写入 `locked_gitlab_traffic_points_per_gb`
4. 租户侧展示价目与说明

## 测试点（映射）

- T1：创建套餐默认流量费=1，可自定义
- T2：`billing_unit` 出现 `gitlab_traffic` / `GB`
- T3：切换套餐锁价更新为新套餐流量价
- T4：描述含「同区域内网不计费」
