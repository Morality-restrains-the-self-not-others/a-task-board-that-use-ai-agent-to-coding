# NFR：多账号切换私有资源隔离

**日期**: 2026-07-15  
**默认等级**: 安全相关 → L3；其余 L2

| 类别 | 等级 | 场景 | 度量 |
|------|------|------|------|
| 安全性 / 隔离 | L3 | A→B 切换后 API 身份不得为 A | 鉴权测试 + Vitest |
| 可用性 | L2 | 单账号登录（仅 Session）仍可用 | 无 Token 时 Session 仍认证 |
| 性能 | L2 | 切换仍一次 activate + 整页刷新 | 无额外轮询 |
| 可观测性 | L2 | 切换失败打 console/已有日志 | 沿用现有 |
| 兼容性 | L2 | 与网关 Token 优先一致 | 文档对照 |

## 领域影响

- 认证边界：ActiveAccount 必须同时清理 Django Session cookie。
- 无新聚合；无新表。
