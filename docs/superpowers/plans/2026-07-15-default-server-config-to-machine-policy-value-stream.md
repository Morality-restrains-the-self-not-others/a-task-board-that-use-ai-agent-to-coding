# 价值流：默认服务器启动配置迁入机器节点策略

## 主价值流（最小增量）

```
租户管理员进入工作空间管理
  → 打开某工作空间「机器节点」
  → 在「默认服务器启动配置」分区选择授权
  → 配置并保存默认启动参数
  → 项目页「快速应用默认模版」下拉出现该预设
  → 一键应用到项目运行模版
```

## 测试点

| ID | 测试点 | 对应验证 |
|----|--------|----------|
| TP1 | 机器策略模态可见默认配置分区 | Playwright / 组件断言 |
| TP2 | 点击「配置默认启动」打开 SetDefaultConfigModal | Playwright |
| TP3 | 云平台授权行无「默认服务器启动配置」按钮 | Playwright / 单元 |
| TP4 | 项目页空态文案指向机器节点 | 文案断言 |
