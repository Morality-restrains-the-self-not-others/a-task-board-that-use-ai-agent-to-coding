# 价值流增量：订单详情申请退款

```
支付成功详情页 → 阅读已消耗说明 → 申请退款 → 确认弹层（消耗明细）
  → POST refund-applications → 待审批 → 超管批准 → 原路退 + 收回剩余配额
```

测试点：

| ID | 场景 | 期望 |
|----|------|------|
| VS-R6 | 已支付微信订单详情 | 横幅有申请退款按钮 + 「已消耗的资源无法退回」 |
| VS-R7 | 本单已有 pending | 显示退款中，无申请按钮 |
| VS-R8 | 确认提交 | POST 带 order_id 与 Idempotency-Key |
| VS-R9 | 同单带 Key 重放 | 返回已有申请，不插入第二行 |
