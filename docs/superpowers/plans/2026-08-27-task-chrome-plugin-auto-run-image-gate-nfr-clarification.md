# NFR 澄清：Chrome 插件自动运行与已安装镜像挂钩

- **Date:** 2026-08-27
- **Increment:** Inc-1（UI 钳制 + 客户端提交门禁，无新网络写路径）

## 路径分片键强制审视

| 路径 | 类型 | 分片 ID | 判定 | 可伸缩性 | 动作 |
|------|------|---------|------|----------|------|
| 浮窗/面板镜像 select 与自动运行 checkbox（本地 DOM） | 前端控件 | 无 | 无分片 ID | **L0** | 单用户本机 UI。升级触发：若镜像选择要跨设备同步再评估 |
| GET 已安装镜像（既有） | HTTP GET | `companyId`/`tenant_id` | 合适（租户目录边界） | L0（本增量不改该调用） | 不新增请求 |
| 创建任务 POST（既有） | HTTP 写 | `workspace_id` + 租户上下文 | 合适 | 本增量不改契约 | 仅少一次注定失败的 auto_run 请求 |

L0 理由：无新寻址路径。升级触发：租户镜像目录分页/分片查询。

## 幂等性强制审视

| 路径 | 副作用 | 等级 | 重复触发源 | 业务重复边界 | 幂等键 | 重放语义 |
|------|--------|------|------------|--------------|--------|----------|
| 切换镜像 / 重算自动运行控件 | 无（纯 UI） | **L0** | 连点 select | 不适用 | 无 | 同一镜像再选仍单值 |
| `validateCreateTaskForm` 拦截 | 无（未发请求） | **L0** | 双击创建 | 不适用 | 无 | 重复点击仍拦截 |
| 创建任务 POST | 有（既有） | 维持既有 | 双击创建 | 一次创建意图 | 既有点击门闩 | 本增量不改 |

禁止把「禁用 checkbox」当成服务端幂等。云启机仍由既有 create + `validateAutoRunPrerequisites` 负责。

## 质量场景

1. **刺激**：允许自动运行的项目、镜像为空。**响应**：自动运行 disabled，提示「请先选择已安装镜像」；镜像标签 `*自动运行必选`。
2. **刺激**：用户选择已安装镜像。**响应**：自动运行 enabled，默认勾选。
3. **刺激**：用户清空镜像。**响应**：自动运行 unchecked + disabled。
4. **刺激**：`auto_run=true` 提交且无镜像。**响应**：客户端文案「请先选择已安装镜像」，无 `data-traceId`。
5. **刺激**：`auto_run=false` 无镜像提交。**响应**：不因镜像拦截。
