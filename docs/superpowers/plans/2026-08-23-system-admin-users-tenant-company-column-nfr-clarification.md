# NFR 澄清 — 用户列表所属租户公司列

- **日期**: 2026-08-23
- **价值流**: `docs/superpowers/plans/2026-08-23-system-admin-users-tenant-company-column-value-stream.md`
- **默认等级**: L2；安全沿用超管门禁 L3

## 路径分片键审视

| 路径 | 分片 ID | 判定 | 可伸缩性等级 | 结论 / 动作 |
|------|---------|------|-------------|-------------|
| GET `/api/system-admin/users/` | 无 | 缺键 | **L0** | 平台超管全局用户目录；分页 ≤50；非租户流量。升级触发：单页 P95 > 500ms 或用户表 > 100 万且超管检索变慢时，再评估按 `q`/归档分区，不按 tenant 切（本路径本就是跨租户运营） |
| FE `/system-admin/users/` | 无 | 缺键 | **L0** | 管理后台单页，操作人数极少。升级触发：同 API |
| POST `/api/internal/tenant/members/batch-get/` | `user_ids[]` | 按用户点查，非租户分片键 | L2 | 已有 IN 查询 + 500 上限；调用方只传当前页 ID。不把 `user_id` 当消费幂等键 |

无分片 ID 标 L0 的理由：超管低频跨租户只读目录 + 已分页 + 写明升级触发。

## 幂等性审视

| 路径 | 副作用 | 重复触发源 | 业务重复边界 | 幂等键 | 重放语义 |
|------|--------|------------|--------------|--------|----------|
| GET `/api/system-admin/users/` | 无 | 刷新/翻页 | — | — | **L0** 同一快照 |
| POST `members/batch-get`（taskAuth 出站） | 无（只读） | 列表重试 | — | — | L0 重复读 |
| FE 打开页面 / 搜索 | 无 | 连点搜索 | — | — | Anti-Replay-OK: 只读 GET，不生成 Idempotency-Key |

无 HTTP 写、无 Kafka、无 Webhook、无 timer。禁止用 `tenant_id`/`user_id` 作消费键 — 本增量无消费者。

## 类别定级

| 类别 | 级别 | 说明 |
|------|------|------|
| 可伸缩性 | L0 | 超管全局列表；升级触发见上 |
| 数据一致性 | L1 | 列表与成员关系短窗口最终一致可接受 |
| 安全 | L3 | 超管 + 内部密钥；不对租户暴露他户公司 |
| 可用性 | L2 | 租户服务失败不阻断列表 |
| 性能 | L2 | 每页一次 batch-get，超时 5s |
| 可观测性 | L2 | warn 失败原因 + user_count/duration_ms；禁密钥 |

## 质量场景

1. 刺激：超管打开列表且用户有活跃公司。响应：列显示公司名。
2. 刺激：租户服务 5s 内不可达。响应：列表 200，该列 —。
3. 刺激：普通用户 GET 该 API。响应：403。
4. 刺激：用户仅停用成员。响应：该列 —。

## 领域模型影响

只读投影 `TenantCompanyRef {id, name}` 挂在用户列表 DTO 上；不改变 Company/Member 聚合写边界。无需纠正分片键。
