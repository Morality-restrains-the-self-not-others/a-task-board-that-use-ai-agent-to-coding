# NFR 澄清：工作面板按可访问人或小组过滤

- 日期：2026-07-15
- 默认级别：L2 Standard（auth 相关读接口保持既有 L3 鉴权，本迭代不新增强鉴权面）

## 质量属性场景

| 属性 | 级别 | 场景 | 度量 |
|------|------|------|------|
| 可用性 | L2 | 过滤控件加载失败 | 看板仍可用；选项空 + warn |
| 性能 | L2 | 人列表 <200；选组时多 1 次 members GET | 过滤纯内存 O(n)；debounce 非必须 |
| 安全 | L3（复用） | 仅 access 内主体可选 | 见 permission-analysis |
| 可观测 | L2 | 加载失败 console.warn | 无 PII dump |
| 兼容 | L2 | 与机器过滤 AND | 两 chip 可并存 |
| 持久化 | L1（本迭代不做） | 刷新后过滤清除 | 文档声明 |

## 领域影响

无新聚合/表；无 MQ 事件（纯查询/视图例外）。
