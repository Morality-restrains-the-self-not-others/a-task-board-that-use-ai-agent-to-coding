# NFR：去掉 Chrome 插件跨页面任务描述同步

- **Date:** 2026-08-21
- **Levels default:** L0（扩展本机，删除跨 tab 写路径）

## 路径分片键审视

| 路径 | 分片 ID | 判定 | 可伸缩性等级 | 结论 / 动作 |
|------|---------|------|-------------|-------------|
| `chrome.runtime` `syncDescription`（删除） | 无 | 本机消息，非多租户 API | L0 | 删除该路径 |
| 浮窗任务描述 textarea | 无 | 单页 DOM | L0 | 保持各标签页隔离 |
| Kafka / HTTP API | 无本增量路径 | — | L0 | 不改服务端 |

无「缺分片 ID 却声称无可伸缩性」的路径。升级触发：若将来再引入跨设备描述草稿，须带 userId 且不得用跨 tab 广播扇出。

## 幂等性审视

| 路径 | 副作用 | 重复触发源 | 业务重复边界 | 幂等键 | 重放语义 | 等级 |
|------|--------|------------|--------------|--------|----------|------|
| 填写本页任务描述 | 仅本页 DOM | 连续输入 | 本标签页 textarea | 无（纯本地） | 后写覆盖本页 | L0 |
| 已删除的跨页广播 | 曾覆盖它页描述 | — | — | — | 路径移除，不再转发 | — |
| 旧版 content 仍发 `syncDescription` | 无（Unknown action） | 未刷新的旧脚本 | 单条 runtime 消息 | 无 | 不写 storage、不 sendMessage | L0 |

禁止用 `tenant_id`/`user_id` 作本增量幂等键（无事件消费）。

## 其他类别

| 类别 | 等级 | 说明 |
|------|------|------|
| 性能 | L1 | 去掉全 tab 扇出，降低 SW 广播压力 |
| 安全 | L1 | 无新权限；描述不再泄漏到其它标签页 |
| 可观测性 | L0 | 删除同步通道日志；未知 action 走既有 default |
