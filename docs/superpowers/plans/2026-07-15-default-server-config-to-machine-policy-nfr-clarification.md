# NFR：默认服务器启动配置迁入机器节点策略

全部类别默认 **L2（Standard）**。

| 类别 | 级别 | 说明 |
|------|------|------|
| 可用性 | L2 | 嵌套模态可关闭；策略保存与配置保存独立 |
| 性能 | L2 | 无额外列表请求（复用已加载 authorizations） |
| 安全 | L2 | 沿用既有 Cookie 会话与租户隔离 |
| 可维护性 | L2 | 复用 SetDefaultConfig* 组件，避免复制表单 |
| 可观测性 | L2 | 沿用既有 API 与前端 error 展示 |

无 L3 金融/鉴权模型变更。
