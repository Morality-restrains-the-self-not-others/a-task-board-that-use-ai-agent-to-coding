# 价值流分析：移除手机号验证码登录

- 日期：2026-08-24
- 关联设计：2026-08-24-remove-phone-code-login-design.md

## 用户旅程（目标态）

```
新用户                          老用户(已注册手机号)              忘记密码用户
  │                                  │                              │
  ▼                                  ▼                              ▼
注册(手机+验证码+密码)         登录(手机号+密码)            忘记密码 → 手机号+验证码
  │ phone_register                 │ /api/auth/ {phone,pwd}    → 重置密码(新密码)
  ▼                                  ▼                              ▼
登录页(手机号+密码)            ✅ 进入工作面板                新密码登录
```

## 价值主张
1. **安全**：验证码登录是「仅持有短信可达性即可登录」的高风险入口（短信劫持/接码平台）；密码登录要求持密
2. **注册即持密**：注册强制设置密码，登录路径与密码强绑定
3. **遗忘兜底**：验证码能力保留在重置密码场景（一次性、需新密码落地），仍覆盖手机号用户
4. **简化心智**：登录页不再出现「验证码登录」与「密码登录」两种手机方式并存的选择负担

## 价值流节点与度量

| 节点 | 现状 | 目标态 | 度量 |
|---|---|---|---|
| 注册 | 手机+码+密码 | 不变 | phone_register 成功率 |
| 手机验证码登录 | 可用（+自动注册） | **移除** | /api/auth/ {phone,code} → 400 |
| 手机密码登录 | 可用 | 不变 | 登录成功率 |
| 重置密码 | 邮箱链接+手机验证码 | 不变（手机验证码为手机用户主路径） | reset_password_with_code 成功率 |

## 反价值（删除后风险）
- 用户习惯「验证码直登」→ 首次登录需回忆密码；缓解：重置密码路径 3 步可找回
- 接码平台批量注册仍可走 phone_register（注册路径未加码）；缓解：注册已有验证码+邀请码体系，不在本任务范围
