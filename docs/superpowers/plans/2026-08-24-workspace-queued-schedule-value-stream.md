# 工作空间级排队调度 — 价值流分析

- 日期：2026-08-24

## 用户价值流（To-Be）

```
用户在左侧导航点击「工作空间的排队调度」
  → 页面加载工作空间节奏 + 队列快照（GET /api/tenant/{tid}/workspace/{wid}/queue-schedule/）
  → 用户配置：启用开关 + 时间窗（每日起止/并发机器数/自动关闭）→ 保存（PUT）
  → taskEvents timer 每周期 POST dispatch-once
  → TTS 按工作空间分发：未启用/不在窗口 → 全部 deferred；在窗口 → 依序启动已入队任务（≤并发上限）
  → 窗口结束 → 自动关闭拉起机器（auto_close 窗口）
  → 用户回页面看到队列成员状态流转（deferred/queued/starting）
```

## 价值收益
1. 调度配置从「逐顶层任务」收敛为「逐工作空间」：一次配置管全部任务（用户核心诉求）
2. 入口从任务详情深层模态提升为全局左侧导航，可发现性增强
3. 旧配置零迁移零中断：工作空间未配置时回退 task 级节奏（生产稳定）
4. 队列列表工作空间级聚合，含任务标题，可观测性增强

## 成本
- 新增 2 表 + 2 端点 + 1 页面 + 1 导航项 + 分发改造（回退分支）
