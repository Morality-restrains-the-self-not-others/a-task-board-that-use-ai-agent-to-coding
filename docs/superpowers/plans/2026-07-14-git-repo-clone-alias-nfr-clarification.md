# NFR：Git 仓库克隆别名

日期：2026-07-14  
默认等级：L2 Standard

| 属性 | 等级 | 说明 |
|------|------|------|
| 兼容性 | L3 | 旧 `git_repos: string[]` 必须继续工作 |
| 安全 | L2 | sanitize 目录名，禁止路径穿越（`/` `..`） |
| 性能 | L1 | 多一列/字段，可忽略 |
| 可观测性 | L2 | 克隆日志已打印目标目录名，保持 |
| 可用性 | L2 | 别名可选，空则回退 |

## 对领域模型影响

`ProjectRepo` 增加可选值对象属性 `CloneAlias`（字符串，sanitize 后）。
