# NFR 澄清 — 用户列表是否获得分账资格列

- **日期**: 2026-08-23
- **价值流**: `docs/superpowers/plans/2026-08-23-system-admin-users-profit-sharing-qualification-column-value-stream.md`
- **默认等级**: L2；安全沿用超管门禁 L3

## 路径分片键审视

| 路径 | 分片 ID | 判定 | 可伸缩性等级 | 结论 / 动作 |
|------|---------|------|-------------|-------------|
| GET `/api/system-admin/users/` | 无 | 缺键 | **L0** | 平台超管全局用户目录；分页 ≤200；非租户流量。升级触发：单页 P95 > 500ms 或用户表 > 100 万且超管检索变慢 |
| FE `/system-admin/users/` | 无 | 缺键 | **L0** | 管理后台单页，操作人数极少 |
| POST `/api/internal/referral/qualification/active/batch/` | `user_ids[]` | 按用户点查，非租户分片键 | L2 | IN 查询 + 200 上限；调用方只传当前页 ID。不把 `user_id` 当消费幂等键 |

无分片 ID 标 L0 的理由：超管低频跨租户只读目录 + 已分页 + 写明升级触发。

## 幂等性审视

| 路径 | 副作用 | 重复触发源 | 业务重复边界 | 幂等键 | 重放语义 |
|------|--------|------------|--------------|--------|----------|
| GET `/api/system-admin/users/` | 无 | 刷新/翻页 | — | — | **L0** 同一快照 |
| POST `qualification/active/batch`（taskAuth 出站） | 无（只读） | 列表重试 | — | — | L0 重复读 |
| FE 打开页面 / 搜索 | 无 | 连点搜索 | — | — | Anti-Replay-OK: 只读 GET，不生成 Idempotency-Key |

无 HTTP 写、无 Kafka、无 Webhook、无 timer。禁止用 `tenant_id`/`user_id` 作消费键 — 本增量无消费者。

## 类别定级

| 类别 | 级别 | 说明 |
|------|------|------|
| 可伸缩性 | L0 | 超管全局列表；升级触发见上 |
| 数据一致性 | L1 | 列表与资格短窗口最终一致可接受（取消资格后下一页刷新可见） |
| 安全 | L3 | 超管 + 内部密钥；不对租户暴露他人资格 |
| 可用性 | L2 | 资格服务失败不阻断列表 |
| 性能 | L2 | 每页一次 batch POST，超时 5s |
| 可观测性 | L2 | warn 失败原因 + user_count/duration_ms；禁密钥 |

## 质量场景

1. 刺激：超管打开列表且用户资格 approved 未过期。响应：列显示「是」。
2. 刺激：资格服务 5s 内不可达。响应：列表 200，该列 —。
3. 刺激：普通用户 GET 该 API。响应：403。
4. 刺激：资格已取消或过期。响应：该列「否」。

## 领域模型影响

只读投影布尔值挂在用户列表 DTO 上；不改变 ReferralCode 聚合写边界。无需纠正分片键。
