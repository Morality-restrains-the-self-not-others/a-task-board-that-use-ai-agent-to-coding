# NFR 澄清: 创建任务项目仓库可访问性标签

> - 设计文档: `docs/superpowers/specs/2026-05-30-create-task-project-repo-access-label-design.md`

## NFR 概览表

| 类别 | 等级 | 一句话量化 |
|------|------|-----------|
| 性能 | L2 | 单项目预检 P95 ≤ 2s；N 项目并行不串行 |
| 安全性 | L3 | 租户成员校验 + OAuth token 不暴露给前端 |
| 可维护性 | L2 | 旧 github 端点 deprecated 保留 1 版本 |
| 可用性 | L1 | 预检失败不阻塞选项目 |
| 数据一致性 | L0 | 只读预检，无写入 |

## 质量场景

### QS-01: 弹窗打开批量预检延迟

| 要素 | 内容 |
|------|------|
| 类别 | 性能 |
| 等级 | L2 |
| 刺激源 | 用户打开创建任务弹窗 |
| 刺激 | 工作空间含 10 个项目，并行 repo-access-check |
| 制品 | GET repo-access-check |
| 环境 | 正常负载 |
| 响应 | 各请求独立返回，不阻塞 UI 渲染 |
| 响应度量 | 单请求服务端 P95 ≤ 2s |

### QS-02: 未授权仓库不泄露 token

| 要素 | 内容 |
|------|------|
| 类别 | 安全性 |
| 等级 | L3 |
| 刺激源 | 已登录租户成员 |
| 刺激 | 请求他人租户项目 ID |
| 制品 | repo-access-check |
| 环境 | 正常 |
| 响应 | 403，响应体不含 OAuth token |
| 响应度量 | 单测断言 403 + 无 token 字段 |

## 领域模型影响

| NFR 决策 | 模型影响 | DDD 动作 |
|----------|---------|---------|
| 只读预检 L0 一致性 | 无持久化 | 领域服务纯函数，无聚合写入 |
| 安全 L3 | token 在基础设施层解析 | 领域服务接收 token 参数，不直连 gitOauth |

## 跳过声明

- 可伸缩性: 跳过。预检为低频读操作。
- 合规: 跳过。无新 PII 存储。
