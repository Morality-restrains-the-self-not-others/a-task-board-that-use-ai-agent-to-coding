# NFR — 自动 SG 入网白名单

默认级别：**L2 Standard**；安全相关入站策略按 **L3**。

| 类别 | 级别 | 场景 |
|------|------|------|
| 安全性 | L3 | 默认拒绝未授权入站；禁止回退全开 |
| 可用性 | L2 | Phase B 补规则失败不阻断已成功的 RunInstances |
| 性能 | L2 | DescribeInstances 轮询 ≤ ~30s，间隔 2s |
| 可观测性 | L2 | 白名单 CIDR / 撤销全开 可追踪 |
| 兼容性 | L2 | 旧名 SG 复用后收紧；手动 SG 不变 |

## 质量属性场景

1. **S1**：攻击者从非白名单 IP 访问 :8765 → 被安全组拒绝。
2. **S2**：用户 IP 变更后需重新启动或手动改 SG（本期不支持动态刷新）。
3. **S3**：公网 IP 分配延迟 → Phase B 重试；超时则日志告警，启动仍成功。
