# 镜像组图标 — 价值流

- **日期**: 2026-08-28
- **设计**: `docs/superpowers/specs/2026-08-28-image-group-icon-design.md`

## 端到端价值

厂商在门户为镜像组上传图标 → 组元数据带 `icon_url` → 主站镜像市场卡片展示图标。

## 增量（单增量交付）

1. 领域校验 + DDL `icon_file_key`
2. 上传三步 + 创建/更新必填 + 公开 GET
3. 厂商弹窗/列表 + 目录 JSON + taskFE 卡片
4. 回归：空图标 400、直传后创建 201、市场卡片 `<img>`

## 最小可行切片

先后端契约（无图标 400）再前端必填，再市场展示。不拆第二期。
