# 订单电子发票价值流

Mapping the approved design into a value stream.

## 端到端

租户支付成功 → 填写抬头申请 → 管理员审批 → 微信开具插卡 →（可选）退款获批 → 未消耗退款 + 全额红冲受理 → **订单页提醒 72h 内卡包确认冲红** → 回调确认后原票失效 + 剩余成交重开蓝票 → 订单下可见全部发票。

## 增量

| 增量 | 价值 | 测试锚点 |
|------|------|----------|
| I1 申请与挂单 | 用户能提交、订单能列出申请/发票 | T1–T3 T6 F1 F2 F4 |
| I2 审批开具 | 审批后调微信开票缝 | T4 T5 T10 |
| I3 退款红冲重开 | 有蓝票时 reverse±reissue | T7–T9 F3 |
| I4 管理端 Tab | 运营可审批 | F5 F6 |
| I5 冲红 72h 确认提醒 | 退款后客户知悉须在 72h 内确认，否则冲红失效 | T12 F7 |

## 最小可交付

I1+I2 即可开票；I3 满足退款票面；I4 运营入口。本迭代一次交付 I1–I4。
