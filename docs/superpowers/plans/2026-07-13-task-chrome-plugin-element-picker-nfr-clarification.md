# NFR 澄清：悬浮面板指针选择页面元素

**日期**: 2026-07-13  
**默认等级**: L2 Standard

| 类别 | 等级 | 说明 |
|------|------|------|
| 可用性 | L2 | Esc 取消；按钮态清晰；弹窗可取消 |
| 性能 | L2 | pick 模式仅 mousemove/click 监听；无轮询 |
| 安全 | L2 | 不读 password value；文本截断 |
| 兼容性 | L2 | 主文档 DOM；iframe/Shadow 本版不做 |
| 可观测性 | L2 | `console.log` 记录 pick 开始/结束/确认（无敏感值） |
| 可测性 | L2 | 核心格式化为纯函数 + node:test |

### 质量场景

1. **给定** 打开浮窗并进入 pick，**当** 用户 Esc，**则** 退出 pick 且描述不变  
2. **给定** 选中按钮并填写期望，**当** 确认，**则** 描述末尾出现含 URL 与期望的块
