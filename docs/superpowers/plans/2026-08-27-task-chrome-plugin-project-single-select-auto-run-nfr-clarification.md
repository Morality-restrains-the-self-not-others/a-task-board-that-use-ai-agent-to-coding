# NFR 澄清：Chrome 插件项目单选 + 自动运行随项目能力

- **Date:** 2026-08-27
- **Increment:** Inc-1（UI 钳制，无新网络写路径）

## 路径分片键强制审视

| 路径 | 类型 | 分片 ID | 判定 | 可伸缩性 | 动作 |
|------|------|---------|------|----------|------|
| 浮窗/面板项目 radio（本地 DOM） | 前端控件 | 无 | 无分片 ID | **L0** | 单用户本机 UI；升级触发：若改为服务端保存选择偏好再评估 `user_id` 是否过粗 |
| GET 工作空间项目列表（既有） | HTTP GET | `workspaceId`（+ `companyId`） | 合适（工作空间是列表边界） | L0（本增量不改该调用） | 不新增请求 |
| 创建任务 POST（既有） | HTTP 写 | 请求体含 `workspace_id` / 租户上下文 | 合适 | 本增量不改契约 | payload 项目数 0–1，无新路由 |

L0 理由：无新寻址路径、无新列表扫描、流量仍是操作者本机一次选择。升级触发：若选择状态要跨设备同步或服务端审计每次点选。

## 幂等性强制审视

| 路径 | 副作用 | 等级 | 重复触发源 | 业务重复边界 | 幂等键 | 重放语义 |
|------|--------|------|------------|--------------|--------|----------|
| 切换项目 radio / 计算自动运行控件状态 | 无（纯 UI） | **L0** | 连点 radio | 不适用 | 无 | 同一项目再点仍单选 |
| 创建任务 POST | 有（既有） | 维持既有（前端点击门闩 + 服务端创建） | 双击创建按钮 | 一次创建意图 | 既有 `Idempotency-Key`（若有） | 本增量不改 |

禁止把「禁用 checkbox」当成服务端幂等。资金/云启机仍由既有 create+start-vm 路径负责。

## 质量场景

1. **刺激**：用户选 `default_auto_run !== true` 的项目。**响应**：自动运行 disabled 且 unchecked，提示「当前项目未允许自动运行」。
2. **刺激**：用户改选允许自动运行的项目。**响应**：控件启用且默认勾选；用户可取消勾选后创建。
3. **刺激**：工作空间列表为空或尚未选择项目。**响应**：自动运行 disabled，提示「请先选择项目」。

## 领域模型影响

- 引入值对象 `AutoRunControlState{enabled, checked, hint}`，由所选项目推导。
- 不新增聚合/事件。
