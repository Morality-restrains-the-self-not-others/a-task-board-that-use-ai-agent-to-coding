# 价值流：厂商版本行下架/删除

- **Date:** 2026-08-29
- **Increment:** 单一垂直切片 — 厂商在版本行看到并完成下架/删除

## 触发到价值

1. 厂商打开门户 → 展开镜像组 → 看见已上架版本行（含操作列）。
2. 非激活已上架：可「下架」或直接「删除」。
3. 激活已上架：可「下架」（取消激活并变草稿），不可删。
4. 草稿/已驳回：可「删除」。
5. 公开目录不再展示已删/已下架版本。

## 增量（仅 1）

MVP = 布局可见操作列 + 领域守卫 + 确认弹窗。不拆第二期。

## YAML

`conf/value-stream.yaml` 增加 `vendor-container-image-lifecycle`（域：镜像市场）。
