- **日期**: 2026-08-23
- **增量**: 用户列表只读列

## 当前价值流（增量）

1. 超管打开 `/system-admin/users/`。
2. 前端 `GET /api/system-admin/users/?limit=&offset=&is_archived=`。
3. taskAuth 查 `auth_user` 分页，批量补登录方式 / 推荐人。
4. **新增**：同一批 `user_id` 调 taskTenantService `members/batch-get`，聚合活跃公司。
5. 表格「所属租户公司」列渲染名称；无归属显示 —。
