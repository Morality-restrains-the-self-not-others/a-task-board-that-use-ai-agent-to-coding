- **日期:** 2026-08-22

Mapping the approved design into a value stream.

## Related Value Streams

扩展 F-082「推送并创建PR」，不是全新用户旅程。依赖：OAuth 绑定、zTree 推送已返回 html_url。

不修改容器本地「合并到目标分支」价值流。

## 端到端价值流

```
成员在任务评论执行细节推送
  → Git 平台创建 PR/MR
  → 会话出现嵌套回复（PR 链接）
  → 成员看到合并状态
  → （可选）一键合并
  → 状态变为已合并 + 审计可查点击人
```

## 增量

| # | 增量 | 用户可感知结果 | 测试点 |
|---|------|----------------|--------|
| V1 | 幂等 PR 回复评论 | 推送后父评论下有链接回复 | U1 U2 U3 |
| V2 | 合并状态展示 | 打开详情可见未合并/已合并 | U4 U6 U7 |
| V3 | 一键合并 + 审计 | 点击后远端合并，审计有 user_id | U8 U9 U10 |

V1 为最小可交付；V2/V3 同期交付（无状态则一键合并不可用）。

## 不做的价值

- 站内 diff 审查
- 自动合并（无点击）
