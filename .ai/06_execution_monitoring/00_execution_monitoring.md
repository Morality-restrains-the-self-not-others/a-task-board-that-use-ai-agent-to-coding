# 五、执行与监控
1. **超时处理**：运行超过 1 分钟时，检查是否有报错或用户输入请求
2. **主动决策**：若需用户输入，应基于上下文主动进行合理决策
3. **项目运行**：运行脚本为项目根目录下的 `run.sh`，该脚本会持续运行，应放到后台运行并监控日志，如有报错及时修复
4. **Docker Compose 管理**：
   - 运行项目时，根据需要启动或关闭对应的 `docker-compose.yml` 文件
   - 启动前确保所有必要的服务通过 Docker Compose 正常运行
   - 运行完成后及时关闭不再需要的服务，避免资源浪费
   - 启动命令：`docker-compose up -d`
   - 关闭命令：`docker-compose down`
5. **事件处理脚本管理**：当新建事件处理脚本后，应该重启消费者服务，以确保新的事件处理逻辑能够生效
6. **终端长时间无输出处理**：当终端长时间未返回输出时，应自动跳过该操作，继续执行后续任务，避免无限等待
7. **Playwright测试完成检测**：当终端输出中出现 "Serving HTML report at" 时，说明Playwright测试已经运行完成，应该自动中止对应命令的执行
8. **临时文件清理**：智能体修改完代码后，应该尽量移除不必要的临时文件、测试文件，保持代码仓库的整洁性
