# awesome-design-md catalog — what to borrow

Source: [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (~73 DESIGN.md files, MIT collection of publicly visible tokens). **Not skills.** Each entry is a visual language dump.

Do not clone the tree into this monorepo. Link and localize.

## Use for this product (B2B workbench)

| Family | Upstream (examples) | Borrow | Do not borrow |
|--------|---------------------|--------|----------------|
| Dense product UI | Linear, Superhuman, Sentry | Hairline panels, one accent, technical density | Their hex, custom display faces, brand marks |
| Trust / money | Stripe, Wise, Coinbase | Clear hierarchy, restrained motion on billing | Stripe gradient purple, mascots |
| Workspace / messaging | Notion, Intercom, Cal.com | Soft surfaces, readable forms | Notion serif as product UI font |
| Docs | Mintlify | Reading measure, green-as-success only | Replacing 紫曜 with Mintlify green |

## Use only for one-off marketing / artifacts

Vercel, Cursor, Runway, ElevenLabs, Framer — cinematic dark heroes. Out of scope for taskFE chrome (`frontend-design` / `theme-factory` instead).

## Do not use as product baseline

Automotive (BMW, Ferrari, …), retro (Dell 1996, Nintendo 2001), Nike / photography-first retail. Wrong density and brand risk.

## How to inspect a template

```text
https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/<slug>
https://getdesign.md/<slug>/design-md
```

Read YAML `colors` + Components + Do's. Then follow `localize.md`.
