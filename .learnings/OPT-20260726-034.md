# OPT-20260726-034: VIP 会员体系后续优化建议

**Status**: pending
**Created**: 2026-07-26
**Related**: [[resource-order-system]] [[pricing-restructure-remove-normal-task]]

## 背景

已完成 VIP 会员体系 v1 实现：
- 普通会员（normal）：可购买任务帖
- VIP1：可购买任务帖 + GitLab 磁盘 + GitLab 流量
- 注册用户默认普通会员
- 累计消费满 100 元自动升级 VIP1

## 后续优化建议

### 1. 多级 VIP 扩展（VIP2/VIP3）
- VIP2 门槛建议：累计消费满 500 元
- VIP3 门槛建议：累计消费满 2000 元
- 等级权益差异化：折扣率、专属资源、优先支持
- 实现方式：在 `canPurchaseResource` 基础上增加权益配置表

### 2. 月度权益体系
- VIP1 月度免费 GitLab 流量配额（如每月赠送 5 GB）
- VIP1 月度免费任务帖配额（如每月赠送 10 帖）
- 实现方式：添加 `billing_membership_benefit` 表 + 定时发放逻辑

### 3. 前端会员中心页面
- 显示当前会员等级、累计消费、距下一级还差多少
- 升级动画/通知
- VIP 特权说明页面
- API: `GET /api/tenant/{id}/billing/membership/` 已就绪

### 4. 运营工具
- 管理员手动升级/降级 API
- 会员等级变更日志（审计）
- 会员统计分析面板

### 5. 降级机制
- 当前 VIP1 是永久升级，无降级
- 若后续引入月度考核，需添加降级逻辑

**Why**: 为后续会员体系迭代提供方向指引，避免重复分析。
**How to apply**: 按优先级逐个迭代，每次迭代前先评估当前业务需求。
